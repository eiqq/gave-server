# 공포 장치 조사: 동아시아 매체

게이브 100종 추가 설계에 쓰려고 동아시아 매체의 공포 장치 145개를 모았다(2026-11-12, research_east). 갈래는 판초법사 후속 회차, 한국 웹소설과 웹툰, 한국 영화와 드라마, 한국 전설과 민담, 학교와 군대 괴담, 일본 요괴, 일본 도시전설과 넷 괴담, 일본 호러 만화, 일본 크리처 만화와 애니, 일본 괴수물, 일본 게임과 영화, 중국 신화와 전설, 중국 역사와 민속, 중국 웹소설과 SF와 인터넷 괴담, 동남아 괴담이다. 같은 내용의 기계용 자료는 같은 폴더의 `공포장치_동아시아.json`(객체 배열)이고, 이 글은 그 JSON 에서 `build/research_east/make_md.py` 로 만들었다(JSON 을 고치면 이 글도 다시 만든다).

사용자 요구(2026-11-12) 가운데 이 조사가 맞춘 것: 거대한 게이브(땅과 하늘, 사람 수십 배, 하늘을 덮음, 지평선에서 걸어옴, 땅이 흔들림)와 절망감, 압도감, 끝없는 수, 피할 수 없음, 끈질긴 추적, 불어남. 그리고 '게이브 데미지가 너무 적어', '플레이어를 노려야 하는데 안 노려'에 맞춰 사람을 적극적으로 노리고 아프게 때리는 장치를 골랐다. 몸꼴은 엔드 막대기 둘이 펄럭이는 꼴(촉수, 지느러미)을 피해 다리로 걷는 것, 바퀴, 탑, 새장, 상자, 땅의 입, 그림자, 하늘 판 같은 꼴로 적었다. 보스는 다른 담당이 만들므로 여기서는 보스 설계를 하지 않았고, 보스와 잇기 좋은 장치만 표시했다.

## 읽는 법

- 칸: `key`(영문 이름), 원리(무섭게 만드는 원리), 갈래(매체), 게이브 행동(구조물 없는 황야에서 사방으로 몰려오는 게이브로 옮긴 생각), 몸꼴(촉수가 아닌 것 위주), 겹치는 종(지금 55종 가운데 장치가 겹치는 종 번호), 꼬리표, 확인, 출처(작품명이나 전설 이름과 주소, 내부 기록용).
- JSON 에는 과제가 정한 칸(key, principle, kind, source, idea, shape, overlap) 말고 `tags`(꼬리표 배열)와 `checked`(확인 정도) 두 칸을 더 넣었다.
- 확인 칸: **읽음** = 이번이나 지난 실행에서 문서를 직접 열어 읽음(WebFetch 가 요약해 돌려주므로 문장 단위 세부는 엇갈릴 수 있음). **검색 요약** = 검색 결과 요약으로만 확인. **일부 확인** = 핵심은 확인했고 세부 일부는 기억. **기억** = 이번에 확인하지 못함(설계에 쓰기 전에 다시 볼 것).
- 게임 글 규칙: 원리, 게이브 행동, 몸꼴 칸에는 다른 작품 크리처의 이름과 고유 생김새를 쓰지 않았다(출처 칸에만 있음). 원작 생김새와 너무 가까운 몸꼴은 바꿔 적었다: 머리에 접시 → 머리에 인 물동이, 불타는 바퀴 한가운데 얼굴 → 얼굴들이 바퀴살로 둘러선 바퀴, 줄무늬 공 → 흐린 얼굴 공, 푸른 결정 → 종이접기 상자, 네 다리 거미 → 세 다리 솥, 사람 모양 구멍 → 제 몸만 한 땅의 입, 얼굴 기구와 올가미 → 이름 쓴 연과 연줄, 기계 다리 물고기 → 톱니 수레, 얼굴 박힌 등딱지 → 얼굴 박힌 가마, 꿰맨 사람 → 얼굴 염주. 특정 크리처를 부르는 소리(이름이 된 의성어)도 바꿨다. 다만 원리 칸 일부는 원작 장면을 거의 그대로 풀어 쓴 것이라(예: '마주 노려봐야 사라진다') 게임 글로 옮길 때는 게이브 말로 다시 써야 한다.
- 숫자(체력 %, 블록, 초)는 설계 담당이 맞출 첫 값이다. 지금 게임의 판 규칙(중앙 원 마른 돌바닥은 끝까지 안전지대, 전장에서 사람이 그 자리에 일어나지 않음, 아군 피해 없음, 화면 덮기는 한 번에 하나)과 부딪히지 않게 적었다.
