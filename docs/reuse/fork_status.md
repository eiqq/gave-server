## gun API for later workers
- Guns(GunHost) implements Listener. tick(), equip(p): Arms 새로 만들고 인벤토리를 비운 뒤 권총을 칸 1 에 넣고 듦. 소모품은 equip 뒤에 칸 2 에 넣을 것. forget(UUID): 시야 걷기 속도 되돌림. clearAll(), settle(): 여러 번 불러도 됨, tick 이 2틱 멈추면 저절로.
- test(p, a): 결과 글 또는 null. 처리하는 행동: 쏘기 틱, 재장전, 총 KIND, 수류탄, 수류탄주기 n, 총상태, 배율, 돌기, 탄창, 예비, 바꾸기 0|1|2, 섬광, 탄창빼기, 반동보기, 웅크리기, 탭, 멈춤, 쏜틱, 총색, 누름. 그 밖은 Grenades(수류탄기록)와 ShotFx(폭발, 터짐, 피, 연출수, 자국시험, 예산시험)로 넘긴다.
- 읽기: arms(p) -> Arms. 공개 필드 primary, mag[], res[](Kind.ordinal() 차례), grenades, shots, kills(총과 수류탄으로 죽인 수), hits(맞힌 알 수), hitAt/killAt(판 틱, HUD 적중 표시용). Arms.spec(Kind) 는 배율 건 Spec, Arms.mods() 는 지금 배율.
- held(p): 손에 든 배율 건 Spec, 칸 2 나 빈 주무기 칸이면 null. spec(p, Kind). ammo(p) -> {mag, reserve 또는 -1, 재장전 0..1 또는 -1}, 총이 없으면 null. reloadPhase(p) -> {남은 틱, 단계 길이}, 재장전 중이 아니면 null.
- static: SPECS(배율 없는 기본값). Spec.key/name/mag/damage... 와 Spec.with(GunMods). damageType(Kind), falloff(dist, range), item(Spec), kick(p, yaw, pitch)(상대 회전, 흔들림용). 칸 상수 SLOT_PRIMARY 0, SLOT_PISTOL 1, SLOT_ITEM 2.
- 지급: givePrimary(p, Kind): 탄창과 예비탄 가득, 칸 0 으로 바꿔 듦. refill(p): 주무기 예비탄 가득. refillFull(p, Kind): 그 주무기 탄창과 예비탄 가득. testFire(p, ticks), reload(p).
- ShotFx(GunHost): tick(), clear(). tracer(shooter, eye, end, main), muzzle(p), hit(at, face, Material, dir, full), bloodHit(at, dir, full[, variant BLOOD_RED|BLOOD_PINK]), explosion(at), burst(at). 공개 도구 spawn(... , prio KEY|NORMAL|EXTRA): 예산이 차면 null 이고 grow, drift 는 null 을 받아도 된다. 그 밖에 decal, fx, room(prio), along, scale, ground, material(Material). 세기: used()(예산 쓴 수, BUDGET 50), alive(), decals().
- Grenades(GunHost, Guns, ShotFx) implements Listener: tick(), clear(), throwFrom(p)(arms.grenades 하나 씀), flying(), look(), MAX 2. onSwap 은 우선순위 NORMAL, ignoreCancelled.
- Props(NS gave): load(InputStream|null, Logger), packSounds(byte[]|null), has(key), hasSound(event), soundCount(), item(...), vanillaLook(...), sound(Location|Player, ...), soundAround(...), soundTo(...), soundOn(Entity, ...)/stopAround(...), seedFor(...).
