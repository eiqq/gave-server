# 게이브 서버 리소스팩

마인크래프트 26.3 "게이브" 서버에 접속하면 자동으로 받는 리소스팩입니다. 따로 내려받아 설치할 필요가 없습니다.

- 팬이 만든 비공식 서버용 팩입니다. Mojang, Microsoft 와 관계없습니다.
- 서버는 두 파일을 함께 보냅니다: 모습 팩 `Gave-pack.zip`(모델, 텍스처, 셰이더, 글꼴)과 소리 팩 `Gave-sound.zip`(소리와 음악). 파일마다 자기 릴리스에 있습니다(태그 `pack-<그 파일 sha1 앞 12자리>`). 예전 릴리스에는 소리까지 든 `Gave-pack.zip` 하나만 있습니다.
- 출처와 라이선스는 두 zip 맨 위의 `CREDITS.txt` 와 `LICENSE-*.txt` 에 있습니다.
  - 총 모델: Timeless and Classics Guns(CC BY-NC-SA 4.0, GPL-3.0 표기를 모두 따름), 수정함
  - 글꼴: Galmuri11(SIL OFL 1.1), 한자 한 글자(故)는 Source Han Sans(Adobe, SIL OFL 1.1)로 그림
  - 음악: Kevin MacLeod(incompetech.com), CC BY 4.0
  - 게이브 얼굴 그림: 마인크래프트 유저 _Gave 의 스킨 얼굴을 본뜬 것
  - 총, 수류탄 소리 대부분은 위 모드들에서 가져왔고 원래 출처가 확인되지 않았습니다. 권리자가 요청하면 내립니다.
- 비상업용입니다. 후원, 유료 기능, 광고와 엮지 않습니다.
