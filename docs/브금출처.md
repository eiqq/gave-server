# 브금 출처(배경 음악)

2026-11-12 원정(aud_trip)으로 곡이 늘었다: incompetech 6곡과 OpenGameArt.org 12곡(CC0 2, CC BY 3.0 8, CC BY 4.0 2). 아래 '원정' 절. 그 절 앞의 곡은 모두 아래 문단 그대로다.

처음 두 절의 곡: Kevin MacLeod (incompetech.com), Creative Commons Attribution 4.0 (https://creativecommons.org/licenses/by/4.0/). 곡 페이지(아래 주소, 트랙 페이지 틀)의 'Attribution Code' 칸에 '"곡 이름" Kevin MacLeod (incompetech.com) Licensed under Creative Commons: By Attribution 4.0 License' 가 적혀 있음을 2026-11-11(처음 11곡), 2026-11-12(락 9곡, 페이지마다 받아 그 문구가 있는지 셈) 확인했다. 원본은 `ref/bgm/incompetech/`(받은 그대로), 기계용 정보와 sha256 은 `ref/bgm/_info.json`, 자르기와 다듬기는 `tools/make_bgm.py`. 팩의 `CREDITS.txt` [7] 절에 저작자 표시와 고친 내용이 들어간다.

곡은 incompetech 의 곡 목록(`https://incompetech.com/music/royalty-free/pieces.json`: 제목, 장르, bpm, 악기, 느낌)에서 골랐다. freepd.com 은 2026-11-11 에 닫혀 있었다('Site Closed'). opengameart.org 곡은 쓰지 않았다(보스 신호 뿔나팔만 opengameart 효과음, 아래).

## 싸울 때(웨이브, 보스): 락, 메탈(2026-11-12 사용자 "락 느낌의 신나고 템포 넘치는 브금으로 교체해 봐, 싸울 때")

## 원정: 네 막의 싸움 곡, cue 곡, 보스 추가(2026-11-12 aud_trip)

요청(원정.md 2.1절, 12절, 재미.md 7, 8절, 보스.md 8절): 막마다 싸움 곡 묶음(락의 신남과 빠르기는 지키되 뒤 막일수록 무겁고 어둡게, 막마다 낮음과 높음에 둘 이상), 이동과 추격전, 최후의 저항, 엔딩 크레딧, 보스 앞, 보스 마지막 단계, 쓰러짐 신호, 엔딩. 받은 곳: incompetech.com(곡 페이지 Attribution Code 칸 문구 확인, 위와 같음), opengameart.org(곡마다 글 페이지의 License(s) 칸을 읽음. 받은 기록 `build/aud_trip/oga_music_got.json`, 원본 `ref/bgm/oga/`, 기계용 정보 `ref/bgm/_info.json`). freepd.com 은 여전히 닫혀 있다고 보고 보지 않았다. 귀로는 듣지 못했다: 곡 정보(장르, 악기, 느낌, 만든 이 설명)로 고르고, 소리 크기와 겹침은 `make_bgm.py --check` 로만 확인했다. 들어 볼 mp3 `build/bgm/listen_trip/`(35개, 팩에 들어가는 그대로).
