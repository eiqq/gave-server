# 게이브 서버 구조(모든 작업자가 따르는 계약)

26.3 Paper 플러그인 `kr.gave`(Java 25), 바닐라 26.3 클라 + 서버 리소스팩. 좀비런(`C:/Users/PC/Desktop/클로드/zombierun`)의 총, 연출, HUD, 팩, 시험 도구를 떼어 와 이름만 바꾸고, 게이브 몹 엔진은 새로 짠다. 게임 규칙과 55종 내용은 `docs/게이브도감.md`, 같은 내용의 기계용 자료는 `data/bestiary.json`. 좀비런에서 가져올 것의 지도는 `docs/reuse/*.md`.

## 0. 이름, 포트, 경로

- 플러그인 이름 `Gave`, 메인 `kr.gave.Gave`, 명령 `/gave`(다른 이름 `/게이브`, 권한 `gave.op`), 월드 `gave_plaza`(bukkit.yml generator `Gave`, load STARTUP).
- 시험 서버 `runtime/`: 게임 26200, RCON 26201(비밀번호 `gave-dev`), 팩 8290. 슬롯 N 은 26200+10N, 26201+10N, 팩 8290+N. 시험 클라 폴더 `~/.cache/gave-client*`, 시험 계정 이름은 실제 작품 속 이름(지어낸 이름 금지).
- 팩 이름공간 `gave`. 팩 zip 둘: 모습 팩 `build/Gave-pack.zip`(모델, 텍스처, 셰이더, 글꼴, 언어, 아이템 정의, music.json 같은 데이터)과 소리 팩 `build/Gave-sound.zip`(모든 이름공간의 sounds.json 과 소리 파일). 서버는 둘 다 있으면 한 요청에 모습 다음 소리로 보낸다(`docs/운영.md` '팩 둘'). jar `build/Gave.jar`.
- 시스템 속성 접두 `gave.`(packDir, packPort, packHost, packRepo). 환경 변수는 좀비런의 `ZR_*` 대신 `GV_*`.
- 가운뎃점(U+00B7) 금지(코드 주석, 문서, 팩 글자 어디에도). 소리는 시험 클라에서 늘 꺼짐. 다른 세션의 서버(포트 25940, 26000대, 26100 등)는 건드리지 않는다.

## 2. 시계와 틱

- `Game.now()`: 서버 틱마다 1씩 느는 판 시계(늘 흐름). 셰이더 시간이 필요한 곳(틴트 시작 틱, HUD timed)은 `world.getGameTime()` 을 쓴다(`Game.worldTime()`).
- 메인 루프는 `Game.tick()` 하나(20Hz, 동기). 순서: director.sideTick(모든 상태) → roam(모든 상태, `Roam.tick`) → [LOBBY: director.lobbyTick(우리 개체가 있으면 그 안에서 mobs.tick)] [PREP, WAVE, BREAK, OVER: (WAVE 만 director.tick) → mobs → players → guns → grenades → shotFx → shop → crates] → hud → music. 모듈마다 try 로 감싸 한 모듈이 던져도 그 틱의 뒤 모듈은 돈다(모듈마다 10초에 한 번 기록 '[판] <모듈> 틱 오류').

## 3. 조작(3개)

- 쏘기: 우클릭 누르고 있기(좀비런 총 방식 그대로, 소모품 컴포넌트로 누름을 앎).
- 돕기: 좌클릭(대상을 보고). 쓰러진 동료 일으키기(3초 채널, 2.5블록 안에서 바라보는 동안 계속), 붙은 게이브 떼기, 달래기, 상점 열기(상점 카운터를 보고 우클릭도 됨). 붙잡힌 본인의 탈출은 좌클릭 연타.
- 듣기: 웅크리기(가까운 게이브 속 울음, 흉내 종 정체).
- 그 밖: Q 재장전, F 수류탄(또는 든 소모품 쓰기), 숫자키 1 주무기, 2 권총, 3 소모품.

## 4. 가짜 몹(Gabe)

- 바탕 엔티티 없음. 위치, 속도, 체력은 서버 값이고 화면은 `Body`(item_display 닻 하나 + 필요하면 부품 디스플레이)로만 그린다. 판정은 플러그인 광선(`Mobs` 가 `HitTargets` 를 구현)으로만 한다.
- `Gabe` 하위 클래스가 `tick()` 에서 행동을 짠다. 공통 도우미는 `Gabe` 와 `Mobs` 에 있다(흐름장 따라가기, 돌진, 표적 고르기, 사람 때리기, 무리 닻, 하늘 선회, 붙잡기).
- 종 클래스 이름은 `kr.gave.mob.sp.G01` 처럼 종 번호 그대로다. `Species.create(game)` 이 리플렉션으로 만든다(공용 등록 파일 없음).
- 보상: `Species.reward`(원). 소환, 분열로 생긴 개체는 `noReward = true`.
- 판 규칙(엔진이 모든 종에 건다): 오래 살면 변함(20, 40, 60초), 서로 다른 종 머리 부딪히면 1초 물어뜯기, 체력 25% 아래 사람이 생기면 모두 돌아보기, 디스플레이 점수 예산(몹 200, 효과 50, 재화 30, 고정 20). 사체는 따로 센다(래그돌, `docs/모듈/래그돌.md`): 물리 단계 50(구 10) + 값싼 단계에서 날아가는 조각 150 + 굳은 사체 120 + 꺼지는 중 30 + 납작 사체 40 까지. 사체는 서로 쌓이지만 사람, 게이브, 탄과는 충돌하지 않는다.

## 5. 팩과 모델(틴트 부호 계약)

- 게이브 아이템 정의는 `assets/gave/items/gabe/<종 소문자>.json`(예: `gave:gabe/g01`), 상태는 `custom_model_data.strings[0]` 의 `select` 로 고른다. 종 Java 와 종 팩 스크립트가 같은 상태 이름을 쓴다.
- 펄럭임은 프레임 접기 정점 셰이더: 모델에 자세 N장(최대 8)을 굽고 지금 프레임이 아닌 면은 접어 숨긴다. 얼굴은 멀리 쓰는 면과 3블록 안에서 쓰는 사람 같은 면을 둘 다 넣고 셰이더가 거리로 고른다. 틴트 번호와 `custom_model_data.colors` 칸 배치, 비트 배치는 `Look.java` 와 `tools/gabe/kit.py` 가 정하고 둘이 늘 같아야 한다(팩 담당이 둘 다 쓴다).
- 종마다 팩 스크립트 `tools/gabe/sp/g01.py` .. `g55.py`(모델, 상태, 소리, 화면 덮개 그림, HUD 글귀). `tools/make_gabe.py` 가 모두 불러 `build/gabe/pack_layer/` 를 만든다. 공용 파일을 여러 종 담당이 같이 고치지 않게 하려는 것이다.
- 소리 이벤트 이름 `gave:gabe.<종 소문자>.<이름>`(예: `gave:gabe.g01.flap`). 바닐라 소리 파일을 피치를 바꿔 가리키거나 numpy 로 합성한 ogg 를 쓴다(권리 깨끗한 것만). 모든 신호 소리에 한국어 자막 키.
- 보탠 크리처 소리(2026-11-14, `docs/소리출처.md` '크리처 보강 소리', 합성은 개수를 맡긴 쪽이 허락한 예외): 엔진 공용 `gave:gabe.cry_*`, `move_*`, `flesh_*`, `corpse_*`(`tools/gabe/flesh.py` NEAR, `common.py` 가 구움)와 종 별칭 `gabe.<종>.idle`, `gait`, `gait_<재질>`, `flesh`(`data/gabe_voice.json`, 키트 finish 가 더함, 종 스크립트는 그대로), 먼 저음 `gave:far.*`(`tools/make_far_sounds.py` → `pack_src`). Java 는 `kr.gave.mob.Ears`(가까운 소리, 듣는 사람마다 예산)와 `Horizon.farTick`(먼 저음 층). 설정 `sfx.near`, `sfx.far`, `sfx.farVolume`.
- 팩 생성 순서: `make_pack_src.py` → `make_fx.py` → `make_gabe.py` → `make_director_sounds.py` → `make_far_sounds.py` → `make_bgm.py` → `make_hud.py`(+ `compile_wip.py --name hud --promote`) → `build_pack.py`. 한 번에 `python -X utf8 tools/build_all.py`(검사와 플러그인까지, `docs/운영.md` '빌드'). 셰이더를 고치면 `python ~/.claude/skills/minecraft-shader/scripts/check_shaders.py pack_src --mc 26.3` 이 0 오류.

## 6. HUD

- 좀비런 방식: 사람마다 보스바 하나의 제목에 글리프를 싣고 core/text 셰이더가 신호 색 글리프만 화면 칸으로 옮긴다. 다른 코드는 보스바를 띄우지 않는다.
- 한국어 글귀는 팩을 만들 때 Galmuri11(OFL, `C:/Users/PC/Desktop/클로드/jeomseonmyeon/art/fonts/Galmuri11-Bold.ttf` 를 `gave/art/fonts/` 로 복사)로 미리 그린 이미지 글리프다. 종 이름은 `Species` 에서, 종별 글귀(죽은 이유, 알림)는 `data/phrases/<종>.json`(키 → 글)에서 make_hud 가 모아 그린다. Java 는 글귀 키로 부른다(`Hud.phrase(key)`).
- 설명 글 벽 금지, 배치와 강조로 뜻을 전한다. 처음 쓰는 순간에만 한 줄.

## 7. 판 흐름

전장은 구조물 없는 황야와 중앙 원(`docs/모듈/맵변경_황야.md`, `docs/모듈/감독맵.md`). 대기실도 중앙 원 안이다(옛 대기실 방과 게이브 우리는 설정 `cage`, 기본 꺼짐).

`LOBBY → PREP(10초) → WAVE n → BREAK(25초, 상점, 서 있는 사람 체력 +25%, 죽은 사람 보급 상자 앞 부활) → WAVE n+1 ... → OVER(서 있는 사람 0, 전멸 연출 10초) → 기록 → LOBBY`. 2~3 웨이브에 한 번 웨이브 중에 진짜 팀 보급 상자가 황야로 떨어진다(`Crates`). 혼자서도 돌아가야 한다(시험은 1~2명).

## 8. 시험

- `bash tools/build_plugin.sh`, `bash tools/test_server.sh start|stop|rcon "<명령>"`, `python -X utf8 tools/ingame.py --name <이름> --scenario tools/scenarios/<대본>.json [--fresh-world]`.
- 시험 훅 `/gave 시험 <행동> <이름> [수...]`. 각 모듈의 `String test(Player p, String[] a)` 가 자기 행동이면 결과 글을, 아니면 null 을 돌려준다. `/gave 상태` 는 `state=`, `wave=`, `mobs=`, `alive=` 를 담는다(대본 until 이 읽음).
- 시험 클라는 PC 전체 2대까지. 끝나면 끈다. 증거 사진은 끝난 검증이면 지운다(C: 여유 적음).
