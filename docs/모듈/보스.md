# 보스(10, 20, 30, 35웨이브 엔딩, 45웨이브, 그 뒤 10웨이브마다)

사용자(2026-11-12): "라운드별로 보스도 하나씩 있으면 좋을 것 같아, 10라운드 정도마다", "거대한 절망감이라든지 압도감이 느껴지면 좋겠어", "게이브 데미지가 너무 적어", "게이브 수가 많아야 해". 2026-11-12 0시 실서버 판(31명, 1~34웨이브)에서 운영자(사용자)가 '50라 엔딩'으로 치자고 했다. 판은 끝없이 이어진다.

이 글은 설계다(boss_d, 2026-11-12 새벽). 구현은 다음 단계 작업자가 한다. 숫자는 처음 값이고 게임 안 시험 뒤에 고친다. 읽을 차례: 1~11절(공통) → 맡은 보스 절(12~16) → 17~19절(되풀이, 시험, 요청).

**바뀐 결정(2026-11-12 아침, 사용자)**. 이 글의 옛 숫자와 어긋나면 아래가 이긴다.
- "35라운드를 엔딩으로": 보스 차례는 **10웨이브 B1 산더미, 20웨이브 B2 하늘 덮는, 30웨이브 B4 지평선, 35웨이브 B5 모두의 게이브(마지막, 그 판에서 처음 잡으면 엔딩)**. 엔딩 뒤 60초 쉬고 36웨이브로 이어지는 끝없는 구간은 **45웨이브 B3 에워싸는**, 그 뒤 55, 65, 75, 85, 95 ... 에 같은 차례(B1, B2, B4, B5, B3)로 회차를 올려 다시 나온다. 숨 고르기는 보스와 겹치지 않는 5의 배수(15, 25, 40, 50, 60 ...).
- "보스도 당연하게 엄청나게 절망감 있게 나와야 해": 등장하는 틱에 땅울림, 뿔나팔, 떼의 함성, 하늘이 어두워짐, 큰 그림자, 레터박스, 모두의 화면에 보스 이름 큰 글귀가 한꺼번에 온다(바탕이 함, 11.11절).
- "촉수가 좀 많대": 막대기를 촉수처럼 늘어뜨려 펄럭이는 모양을 줄인다. 막대기는 다리, 가시, 뼈대, 왕관, 새장 창살, 기둥으로. B2 의 촉수는 곧은 갈고리 기둥으로 고쳐 적었다(13절).
- "보스 게이브들은 맵 등을 활용하는 연출": 보스마다 '맵 활용' 한 줄(12~16절)과 바탕의 맵 연출 도구(땅을 잠깐 바꾸고 반드시 되돌림, 11.12절).
- 판 구조가 바뀌는 중이다(설계 중 docs/모듈/원정.md: 중앙 상점이 체력 있는 트럭이 되고 10라운드마다 테마가 있는 네 막). 보스가 트럭도 노릴 수 있게 '지킬 것' 표적 자리만 뒀다(11.13절).
- **바탕(엔진, 감독 고리, HUD, 브금, 기록, 시험용 빈 보스)은 구현돼 있다(boss_infra, 2026-11-12). 보스 하나를 만드는 사람은 11.11~11.13절과 맡은 보스 절만 보면 된다.**

## 0. 바뀌는 규칙

- 도감 공통 규칙의 '체력 막대 달린 단일 거대 몹은 없다', 41웨이브 절의 '보스는 끝까지 없다', 종담당_지시의 '체력 막대 달린 거대 단일 몹(보스) 금지'는 **이 글의 보스 다섯(B1~B5)에만** 풀린다. 일반 종(G01~G55, 앞으로 생길 G56~G155)은 그대로 막대 없이 간다.
- 보스는 종 번호(G)를 쓰지 않고 B1~B5 를 쓴다(11.2절). 새 종 담당이 쓸 G56~G155 와 겹치지 않는다.
- 맵은 그대로(구조물 없는 황야, 중앙 원 R 12, 사람의 끝 R 48, 게이브 고리 R 72~84). 보스가 땅을 고치지 않는다.

## 2. 게이브 DNA 와 압도감(모든 보스)

DNA(빼지 않는다):
- _Gave 얼굴: 키트 얼굴(먼 32 화소, 3블록 안 128 화소)을 거대하게 키워 쓴다. 코앞에 서면 사람 같은 얼굴(땀구멍, 솜털)이 주먹만 하게 보인다. 직접 칠하지 않는다.
- 엔드 막대기 둘 이상: 보스마다 거대한 막대기(10~40블록)를 다리, 기둥, 왕관, 창살, 뼈대, 노로 쓴다(2026-11-12 사용자: 늘어뜨려 펄럭이는 촉수 꼴은 줄인다). 움직임은 느린 젓기와 오르내림(11.5절: 큰 움직임은 부품 보간, 막대기 안 물결은 프레임 접기로 작게).
- 실눈 문법: 보스의 큰 얼굴은 늘 실눈이다. 공격으로 한 사람을 노릴 때만 그 사람 쪽으로 눈을 뜬다(`Gabe.mark`). B5 3단계의 '눈 뜸'이 판 전체에서 큰 얼굴이 처음으로 활짝 눈을 뜨는 순간이다.

압도감 장치(보스마다 골라 씀, 보스 절에 적음):
- 크기와 거리: 화면을 채우는 크기(B2 하늘, B4 지평선), 안개 속 윤곽이 먼저 보임(B1), 사방을 두름(B3).
- 땅울림: 걸음, 내려찍기마다 화면 흔들림(`Guns.kick(p, yaw, pitch)`, 거리에 따라 0.2~1.2도)과 먼지(ShotFx 먼지, 충격파 고리), 낮은 소리.
- 하늘과 빛: 하늘을 어둡게(세계 시각), 안개를 걷어 다 보이게(맑을수록 위험).
- 떼를 거느림: 보스가 나타나면 떼가 1.5초 멈춰 보스 쪽을 돌아본다(경배, 11.4절), 그 뒤 몰려온다. 보스가 살아 있는 동안 떼가 끊이지 않는다(3.3절).
- 사람을 노림: 위협 표(6.2절)로 고르고, 노림당한 사람 화면 조준점 옆에 보스 아이콘(`Hud.mark`).
- 죽음의 물결: 보스가 쓰러지면 그 자리에서 둥글게 퍼지는 물결에 남은 떼가 차례로 쓰러지고 사체가 바깥으로 날린다(3.4절).

## 3. 보스 웨이브 흐름(감독 연결)

### 3.1 언제, 무엇이
- 보스 웨이브는 10, 20, 30, 35, 45, 그 뒤 10웨이브마다(55, 65 ...): `Director.Tune.BOSS_WAVES = {10, 20, 30, 35, 45}` + `BOSS_EVERY = 10`, 몇 번째 보스 웨이브인지 `Director.bossIndex(w)`(10 → 0, 20 → 1, 30 → 2, 35 → 3, 45 → 4, 55 → 5 ...). k 번째의 보스 = `BossDirector.ORDER[k mod 5]`(ORDER = B1, B2, B4, B5, B3), 회차 c = k / 5 + 1(10~45 는 1, 55~95 는 2, 105~145 는 3 ...). 아래 절에 남은 옛 표기(40, 50, 60웨이브)는 이 차례로 읽는다.
- 구현된 보스만 나온다(`Species.Bx.implemented()`). 없으면 그 웨이브는 보통 웨이브이고 서버 기록에 '[판] 보스 Bx 없음, 보통 웨이브' 한 줄. 그래서 B1 하나만 만들어도 판이 돈다.
- 설정(config.yml): `bosses: true`(false 면 보스 웨이브 없음), `bossHp: 1.0`(운영자 체력 배율). 켠 채 바꾸기는 시험 훅(18절).

### 3.3 보스 웨이브의 떼
- 처음 대기열: 그 웨이브 보통 계획(Plan)의 총량 x `BOSS_UNITS` 0.5(보통 웨이브의 50%). 종 묶음과 조합 패는 보통대로 뽑되 다음은 없다: 미리 깔리는 종(PLACED), 새 종 보여 주기(fresh), 쏠림(lean), 숨 고르기, 소리 없는 웨이브, 안개와 밤과 땅 갈라짐 사건, 금빛(G08). 안개와 시각은 보스가 정한다.
- 동시 수 목표: `aliveGoal() x BOSS_ALIVE 0.6`(화면과 예산 몫을 보스에게).
- 대기열이 비었는데 보스가 살아 있으면 `REFILL_EVERY` 400틱(20초)마다 보통 총량 x `REFILL` 0.1 을 그 웨이브 앞잡이, 받침 종으로 더 넣는다. 보스가 죽을 때까지 떼가 끊기지 않는다. 화남(4.7절)이면 2배.
- 보스 몫 예산: 감독 `reserve()` 에 보스 졸개, 떨어지는 얼굴 몫 `BOSS_ROOM` 20 을 더한다(보스 몸 디스플레이는 이미 `budgetUsed()` 에 들어 있다).
- 막힘 정리(STALL)와 미리 깔린 것만 남았을 때 끝내기(LINGER)는 보스 웨이브에서 끈다(보스가 살아 있으면 웨이브는 끝나지 않는다).
- 보스가 부르는 졸개는 `child`(보상 0, 감독 체력 배율 없음, 몹 예산 200 안). 감독 대기열 떼는 보통 보상.
- 사람 수와 떼: 보통 웨이브 공식 그대로(UNITS_POW, HP_POW, crowdMul)라 30명이면 떼도 그만큼 두껍다. 보스 체력은 4절이 따로 정한다(crowdMul 을 쓰지 않음).

### 3.4 웨이브 끝: 무너짐 물결
- 보스 체력 0 → 죽음 연출 → 20틱 뒤 보스 자리(B3, B4 는 술래, 얼굴 자리)에서 물결이 1블록/틱으로 퍼진다(반지름 120 까지).
- 물결이 지나간 살아 있는 게이브는 모두 죽는다: `Damage(남은 체력, EXPLOSION, by = null, at = 물결 중심 쪽으로 1블록 당긴 자리, dir = 바깥)`. 래그돌이 바깥 위로 날린다. 보상 없음(noReward 켬). 단 죽음 결과 종(G38, G52, G50)은 사람이 잡은 것처럼(noReward 끔, reward 0) 죽인다: 업힌 사람이 손실 없이 풀린다(Players 시험 훅 '더미죽이기' 와 같은 방식). 먹힌 사람은 엔진 `freeFrom` 이 풀어 준다.
- 하늘 종도 같다. 물결 소리는 사람마다 그 사람 쪽 물결 자리에서 낮은 쿵 하나(`gave:boss.wave`).
- 물결이 끝나고 살아 있는 것이 0 이면 waveDone. 감독 `removeLeftovers` 는 마지막 안전망.

### 3.5 전멸 때 보스 승리 연출(보스마다 한 줄, 판 끝 연출 200틱 안)
- B1: 중앙 원 가운데로 걸어가 보급 상자 위에 엎어진다. 무더기 얼굴들이 일제히 킥킥.
- B2: 천천히 내려앉아 중앙 원을 덮는다(높이 3). 화면이 그 그림자로 어두워진다.
- B3: 고리가 반지름 0 까지 조여 열여섯 얼굴이 중앙 원에 맞닿아 안쪽을 본다(모두 눈 뜸).
- B4: 두 눈을 활짝 뜬다. 노란 빛이 경기장 전체를 덮는다(바닥 빛 자리 여럿).
- B5: 중앙 원을 두 팔로 감싸 안고 큰 얼굴을 원 위에 내려놓는다.

| 탄약 | 모두 `guns.refillAll(p)` |
| 보급 상자 | 보스 사체 옆에 진짜 보급 상자 하나(`crates.drop(at)`, 한도 MAX_LIVE 2 를 넘으면 건너뜀) |
| B5 더 | 엔딩 재화 2000 더, 무기 랜덤 상자 한 번 공짜(wpn12 API 가 생기면). 없으면 모두에게 전설 등급 총 제안(`shop.offerGun`) |

- 보스 개체는 `reward = 0`, `noReward = true`(피해 기여로 나누지 않음, 감독 '쪼개짐' 변이에서도 빠짐). 처치한 사람 kills 는 엔진이 올린다.
- 기록: 보스마다 걸린 초와 사람 수를 Records 에 남긴다(19절 요청).

## 4. 체력

### 4.1 공식
```
maxHp = H[b] x (D(w) / D(w_b)) x P(N) x C(c) x bossHp(설정)
H     = { B1 18500, B2 20000, B3 32000, B4 29000, B5 56000 }   w_b = 10, 20, 30, 40, 50(H 를 맞춘 기준 웨이브. 나오는 웨이브가 아니다)
D(w)  = 60 + 4.8 x w          사람 하나의 지속 화력(초당 피해) 어림
P(N)  = N^0.84, N 이 1 이면 x0.65, 2 면 x0.8      N = 보스가 나올 때 판에 든 사람 수(players.inPlay())
C(c)  = 1 + 0.25 x (c - 1)    회차 배율
```
- D(w) 는 `tools/balance_sim.py --skill 0.7 --table`(build/boss_d/sim_skill07.txt)의 '1인 화력(초당)'에 맞춘 직선이다: 10웨이브 99~108, 20 154~167, 30 204~211, 40 250~254(모의 값, 명중 전).
- 보스에 실제로 들어가는 1인 초당 피해 E = D(w) x 명중 0.8 x 몰두 f x 약점 덤 1.15. 몰두 f 는 떼 처리, 피하기, 맞지 않는 시간 몫: B1 0.6, B2 0.45, B3 0.55, B4 0.4, B5 0.5.
- 목표 시간: 5명 240초, 30명 180초(B5 는 x1.3). 이 두 점을 맞추면 사람 수 지수가 0.84, H[b] = D(w_b) x f x 286(B5 는 x1.3).
- 일반 게이브의 crowdMul(접속자^0.45)을 쓰지 않는다: 모두가 한 표적을 쏘므로 보스 체력은 사람 수에 거의 비례해야 한다.
- **상수는 한곳에 있다: `BossDirector.Tune`** 의 `H`(보스 번호 1..5 차례), `H_AT`(w_b), `DPS_BASE` 60, `DPS_PER_WAVE` 4.8, `PEOPLE_POW` 0.84, `PEOPLE_SOLO` 0.65, `PEOPLE_DUO` 0.8, `CYCLE_HP` 0.25, `CYCLE_FLOOR` 1.25, `EXPECT`(예상 싸움 초 표), `EXPECT_B5` 1.3. 파워커브 담당이 체력 표를 다시 내면 여기만 고친다(켠 채 바꾸기 `/gave 시험 보스 x 균형 H <보스 번호> <값>`). `Species.Bx.hp` 는 도감에만 쓰이고 공식은 읽지 않는다.
- 35웨이브 엔딩으로 차례가 바뀌어도 표(H, w_b)는 그대로 뒀다: D(w) / D(w_b) 가 실제 나오는 웨이브에 맞춘다(B4 는 30웨이브에 29000 x 204 / 252 = 23,500, B5 는 35웨이브에 56000 x 228 / 300 = 42,600, B3 는 45웨이브에 32000 x 276 / 204 = 43,300). 4.3절의 걸리는 시간은 같다.

### 4.4 사람 수가 바뀔 때
- 들어오거나 나가면 N 을 다시 재고 maxHp 를 다시 계산하되 지금 체력 비율(hpFrac)은 그대로 둔다(체력 = 새 maxHp x 비율). 쓰러짐, 죽음, 갇힘은 N 에서 빼지 않는다(쉬는 시간까지 못 쏘는 것이 벌).
- 1초에 한 번만 다시 잰다.

### 4.5 화력 보정(권장, 선택)
- 총 담당(wpn12)이 `Guns.sustainedDps(Player)`(지금 주무기의 지속 초당 피해: 피해 x 산탄 수 x 연사 x 탄창/(탄창 + 연사 x 재장전 초) x 강화, 증강, 특성 배율)를 만들면, 보스가 나올 때 판에 든 사람의 평균 S 로 D(w) 를 바꾼다: `D = clamp(S, 0.6 x D(w), 1.6 x D(w))`. 무기 종류가 늘거나 밸런스(bal12)가 바뀌어도 보스 시간이 저절로 맞는다.
- 없으면 D(w) 공식 그대로. 어느 쪽을 썼는지 '[판] 보스' 기록에 남긴다.

### 4.6 단계 전이 보호
- 체력이 문턱을 넘는 순간 전이 50틱: 받는 피해 x0.25, 체력은 다음 문턱 - 1% 아래로 안 내려간다(몰아 쏴서 단계를 건너뛰지 않게). 전이 동안 보스는 포효하며 모습을 바꾼다.

### 4.7 화남(시간 제한 대신)
- 싸운 시간이 `2.2 x 예상 시간(4.3절 표, 사람 수로 보간)`을 넘으면 화남: 다시 쓰기 x0.7, 피해 x1.25, 떼 보충 2배, HUD 이름 빨강 깜빡임, 알림 `bs_enrage`. 끝없이 버티기는 없다. 팀이 무너지면 판이 끝난다.

## 5. 사람이 받는 피해
- 보스 피해는 웨이브 피해 배율(`director.dmgMul()`)을 쓰지 않고 이 글의 표 값을 쓴다(사람 방어 armor 만 곱함). bal12 가 dmgMul 을 바꿔도 보스는 그대로다.
- `hitBoss(p, 값, 원인)` = `game.players.hurt(p, 값 x 회차 피해 x 화남 / game.director.dmgMul(), this, 원인)`(Players.hurt 가 dmgMul 을 곱하므로 나눠서 넘김).
- 회차 피해 = 1 + 0.2 x (c - 1), 2배까지.
- 표의 숫자는 '체력 100, 방어 없음'에서 깎이는 양이다. 10웨이브 사람은 보통 100~140, 30웨이브 뒤로는 200 안팎(체력 스탯 +10 씩, 방어 x0.95 씩)이다.
- 붙잡기(`grab`), 넘어짐(`root`), 느려짐(`slow`), 밀침(`knock`)은 Players, Gabe 도우미를 그대로 쓴다. 이미 붙잡힌 사람, 쓰러진 사람에게는 걸지 않는다(서 있는 사람만).

## 6. 공통 문법(신호, 표적, 약점)

### 6.1 신호 문법(모든 보스가 같게: 처음 보는 보스도 읽히게)
| 보이는 것 | 뜻 |
|---|---|
| 빨간 바닥(원, 띠), 안쪽이 차오름 | 다 차면 거기를 맞는다. 밖으로 |
| 검은 그림자 원, 짙어짐 | 위에서 떨어진다. 밖으로 |
| 흰 파도 고리가 바닥을 기어 옴 | 땅에 있으면 맞는다. 뛰어 넘는다 |
| 초록 고리 | 그 안은 안전하다 |
| 노란 빛 자리 | 비춰지면 변한다. 피하거나 그늘로 |
| 보스 눈이 내 쪽으로 뜨임 + 조준점 옆 보스 아이콘 | 다음 공격은 나다 |
| 금빛 화살촉 | 약점이 드러났다. 그쪽을 쏜다 |
| 노래, 소리가 뚝 멈춤 | 규칙 공격(B3 '노래 멈춤') |
| 재난문자 꼴 알림 + 포효 | 단계가 바뀌었다 |

- 큰 소리 하나 = 공격 하나(보스 절의 소리 표). 예고는 최소 12틱(0.6초), 1회차 보통 20~40틱.
- 바닥 표시는 ShotFx 새 종류(19절 요청 kind 15)가 생기면 그것, 없으면 B1 팩의 공용 판 모델(`gabe/b1_warn_disc`, `b1_warn_strip`, `b1_shadow`, `b1_safe`, `b1_wave`: 컷아웃 점묘 그림, 크기는 변환 보간)로 그린다. 발광 테두리, 블록 디스플레이 상자 하나는 쓰지 않는다.

### 6.2 표적(사람을 적극적으로 노림)
- 위협 표: 사람마다 `t[p] = t[p] x 0.992 + 이번 틱 보스에 준 실제 피해`(초당 x0.85 로 식음).
- 점수: `몫(p) + 0.4 x 가까움 + 0.25 x 혼자`. 몫 = t[p] / (모든 t 합 + 1), 가까움 = max(0, 1 - 거리 / 40), 혼자 = 8블록 안 동료가 없으면 1.
- 공격마다 고르는 법(보스 절 표의 '표적' 칸): top(점수 1위, 같은 공격이 바로 앞에 고른 사람은 x0.6), cluster(그 사람 6블록 안 사람 수가 가장 많은 사람), lonely(가장 가까운 동료까지 거리가 가장 먼 사람), near(가장 가까운 사람), dealer(약점에 피해를 가장 많이 준 사람).
- 고른 순간 `mark(p)`(보스 눈이 그 사람 쪽으로 뜨임) + `hud.mark(p, "bx", 예고 틱)`(조준점 옆 보스 아이콘).
- 동시 공격 칸 = 1 + floor(N / 10)(4 까지). 칸마다 공격 하나. ★(넓은 공격)은 한 번에 하나. 두 칸이 같은 사람을 노리지 않는다(사람이 모자라면 됨).
- 사람이 쓰러지거나 나가면 그 공격은 마지막으로 알던 자리로 끝까지 간다(예고가 거짓말을 하지 않게).

### 6.3 약점과 맞는 느낌
- 약점(보스 절 표): 맞힌 사람에게만 짧은 높은 '칭'(`gave:boss.weak`, 대체 바닐라 BLOCK_AMETHYST_BLOCK_HIT 피치 1.6) + HUD 금색 적중 표시(19절 요청 `C_WEAK`).
- 안 먹힘(B4 감은 눈, B2 두꺼운 살의 x0.35 등 0.5 아래): 둔한 '퉁'(`gave:boss.immune`) + 회색 적중 표시(`C_IMMUNE`). 같은 사람에게 10틱에 한 번.
- 약점이 열리면 `hud.point(null, 약점 자리, 열린 틱)`(금빛 화살촉)으로 모두에게 가리킨다. 판에서 처음 열릴 때 한 줄 도움말(`hud.hint`).

## 7. HUD

다른 코드처럼 보스바를 따로 띄우지 않는다. 사람마다 하나인 HUD 보스바 제목에 칸(글리프)을 더한다(`tools/make_hud.py` SLOTS, Hud.java). 19절 요청이 HUD 담당 몫이다.

### 7.1 보스 틀(보스가 살아 있거나 죽음 연출 중일 때만)
```
                 10                    ← WV_NUM 그대로(보스 웨이브는 빨강)
 ━━━━━━━━━━━━━━━━━━━|━━━━━━━━━━━━|━━━━━━━  ●●○   ← BS_BAR 200x6(빨강) + BS_HURT(흰 깎인 몫) + 문턱 눈금 + BS_PH 단계 점
              산더미 게이브              ← BS_NAME(가운데)
          [ 얼굴이 갈라진다 ]             ← 알림 띠는 이동(NT_LOW)
```
| 칸 | 기준(x 비율, y 비율, x, y) | 모양 | 뜻 |
|---|---|---|---|
| BS_HURT | 0.5, 0.0, -100, 27 | `bar_boss`(새 모양: 200 x 6, 64 단계), 흰색 | 방금 깎인 몫(8틱 뒤 지금 값으로, HP_HURT 와 같은 방식) |
| BS_BAR | 0.5, 0.0, -100, 27 | `bar_boss`, 짙은 빨강(0.78, 0.10, 0.12), NOTRACK | 지금 체력 비율 |
| BS_MARK | 0.5, 0.0, -100, 27 | 그림 `bs_notch`(1 x 8 흰 금) | 단계 문턱마다 x = round(200 x 문턱) 에 하나 |
| BS_PH | 0.5, 0.0, 104, 28 | 그림 `pip`(있는 것) | 단계 수만큼 점, 지난 단계와 지금 단계는 흰색, 남은 단계는 흐림 |
| BS_NAME | 0.5, 0.0, 0, 39 | 글귀 `name_bx`(가운데 맞춤) | 흰색, 화남이면 RED_BLINK, 죽음 연출이면 GRAY |
| NT_LOW | 0.5, 0.0, 0, 58 | 알림 띠 | 보스 틀이 있는 동안 NT 대신 여기 |

- 보스 틀이 있는 동안 WV_BAR, WV_LEFT 는 숨긴다(보스 웨이브의 목표는 보스다. 떼 남은 수는 끝이 없음).
- 막대는 64 단계라 단계가 바뀔 때만 보낸다(패킷 적음). 체력이 늘면(B5 삼킴) 막대가 차오른다.
- Java 가 읽는 것: `game.director.bosses.frame()` → `Frame(String nameKey, String key, double frac, int phase, int phases, double[] cuts, boolean enraged, boolean dying)`, 없으면 null(깎인 흰 몫은 HUD 가 스스로 셈).

### 7.2 노림, 약점, 안 먹힘
- 노림당한 사람: `hud.mark(p, "bx", 예고 틱)`(있는 MARK 칸, 보스 아이콘).
- 약점 적중 `C_WEAK`(금색, HIDE, 6틱), 안 먹힘 `C_IMMUNE`(회색, HIDE, 6틱): 있는 적중 표시 모양을 색만 바꿔 새 칸으로.
- 게이지(B4 변이, B2 끌려 올라감 높이): 있는 `hud.meter(p, key, 몫, 틱)`.

### 7.3 다음 웨이브 예고(앞 쉬는 시간)

### 7.4 등장

- 쓰러진 이유 카드는 그대로: 보스 아이콘 `ic_l_bx` + `name_bx` + 원인 `cause_bx_공격`(보스 절).

### 7.6 엔딩 카드(10절)
- `BS_TITLE` 에 `t_end`("아침"), `BS_SUB` 에 `end_sub`("모두 눈을 감았다"), 새 칸 `END_NUM`(0.5, 0.33, 0, 36)에 숫자 `35   mm:ss   사람 아이콘 n`(M 글꼴, 금색). 200틱.

### 7.7 글귀(짧게, 설명 글 벽 금지)

보스마다(팩 스크립트 `phrases()` → `data/phrases/Bx.json`, make_gabe 가 씀): `name_bx`, `t_bx`, `bs_sub_bx`, `bs_bx_p2`, `bs_bx_p3`(B5 는 p4 까지), `cause_bx_*`. 글은 보스 절에.

## 8. 브금(aud12 가 Music 에 만드는 보스 단계)
- 쓰는 곡(aud12 가 고르고 만든다, 이름은 aud12 를 따른다. 여기서는 뜻으로 부름): boss_pre(보스 앞 쉬는 시간, 조여 오는 드론, 선택), boss_intro(등장 한 방 3~5초: 큰 북 + 금속), boss(싸움 되풀이: 사용자 요청대로 락 느낌의 빠르고 신나는 곡, 가장 센 곡), boss_final(마지막 단계: 더 빠르고 무거운 곡, 없으면 boss), boss_down(쓰러뜨림 신호 3~5초), ending(엔딩 한 번 40~60초, 없으면 조용히).
- 켜고 끄기(BossDirector 가 부름):

| 때 | 부름(뜻) |
|---|---|
| 앞 쉬는 시간 시작(다음이 보스) | 쉬는 시간 곡 대신 boss_pre(있으면), 쉬는 시간 끝 신호는 그대로 |
| 보스 웨이브 t=0 | 보통 웨이브 곡을 틀지 않음. boss_intro 한 방 |
| t=INTRO | boss 되풀이 시작 |
| 마지막 단계 전이 | boss_final 로 1~2초 겹쳐 넘김(웨이브 도중 곡을 바꾸지 않는다는 규칙의 예외) |
| 보스 체력 0 | boss 즉시 멈춤, boss_down 한 방, 물결 동안 조용히 |
| 물결 끝(BREAK) | 보통 쉬는 시간 곡 |
| B5 첫 처치 | 모든 곡 멈춤, 40틱 고요, ending 한 번(10절), 그 뒤 쉬는 시간 곡 |
| 전멸 | 보통 over |

- Music 이 매 틱 `game.director.boss.active()`(보스 웨이브 중인가)를 보고 보스 모드면 웨이브 단계 곡 고르기를 하지 않게 한다(aud12 몫). 소리 종류는 지금처럼 VOICE.

## 9. 소리(받은 소리 태그)
- 보스 소리는 합성하지 않는다(키트 `synth` 금지). 받은 소리 `data/sfx_lib.json`(aud12, CC0 또는 CC BY 만, CREDITS 에 적음)에서 태그로 고르고, 없으면 바닐라 소리 파일을 피치를 바꿔 가리킨다(`k.sound(..., vanilla=[...])`, 바닐라 파일은 팩에 들어가지 않음). 키트가 받은 파일을 넣는 길(`files=`)이 없으면 aud12 에 요청(19절).
- 사건 이름 `gave:gabe.bx.이름`(Java `sound(이름, 대체 Sound, 대체 높이, 반경)`), 공용은 `event=` 로 `gave:boss.wave`, `boss.weak`, `boss.immune`, `boss.next`(b1.py 가 만듦). 모든 소리에 한국어 자막. 반경은 넓게(보스 소리는 경기장 어디서나: 96~256).
- 태그(바라는 소리의 뜻, aud12 사전과 다르면 가장 가까운 것): `footstep_giant`, `ground_rumble`, `breath_inhale_big`, `impact_body_huge`, `rock_roll`, `rattle_many`, `giggle_crowd`, `shockwave_ground`, `roar_giant`, `roar_layered`, `flesh_tear`, `collapse_wet`, `wind_howl_low`, `wing_huge`, `gurgle_deep`, `splat_small`, `whip_crack`, `rope_creak`, `gulp_huge`, `drone_descend`, `thunder_far`, `chant_hum`(말 없는 허밍), `clap_huge`, `silence_hit`, `wood_creak`, `snap_break`, `bell_toll`, `deep_bell`, `hum_fluorescent`, `eyelid_wet`, `pillar_impact`, `ground_tear`, `tear_drip_big`, `sigh_giant`, `whisper_many`, `choir_low`, `heartbeat_giant`, `inhale_huge`, `exhale_blast`, `giggle_single`, `click_single`, `dawn_birds`, `hit_crit`, `hit_dull`.
- 노래, 말소리가 든 곡(실제 노래 가사)은 쓰지 않는다.

## 10. 엔딩(그 판에서 B5 를 처음 잡았을 때)
- 차례(쓰러뜨린 틱부터):

| 틱 | 일 |
|---|---|
| 0 | 입속 작은 얼굴이 실눈을 감는다. 보스 틀 막대가 비며 깜빡. 모든 곡 멈춤, 떼 소리 층 멈춤. 살아 있는 모든 게이브: `look.open = false`, `look.freeze = true`, `game.mobs.frozen = true`(40틱): 세상이 멈춘다 |
| 40 | 모두에게 '딸깍'(`gave:gabe.b5.click`). `frozen` 풂. 무너짐 물결(3.4절, 1.5블록/틱) |
| 60 | 보스가 무너짐(래그돌) |
| 80 | 안개 맑음(`director.bossFog(1)`), 세계 시각 13000 → 25000 을 60틱에 걸쳐(틱마다 +200): 밤이 빨리 지나가고 해가 뜬다 |
| 100 | 브금 ending, 엔딩 카드(7.6절) 200틱, 새소리(`gave:gabe.b5.dawn`) |
| 100 | 보상(3.6절 + B5 더) |
| 120 | 기록(Records 엔딩 줄, 19절), 채팅 한 줄 "35웨이브 엔딩: 모두의 게이브(mm:ss, n명, 쓰러짐 k번)" |
| 물결 끝 | BREAK. 엔딩 쉬는 시간 `ENDING_BREAK` 1200틱(60초). 새벽 하늘과 맑은 안개는 쉬는 시간 내내 그대로 |
| 쉬는 시간 끝 4초 전 | 세계 시각이 70틱에 걸쳐 13000 으로(낮이 빨리 지나가 다시 저녁), 안개 기본으로 |
| 다음 | 36웨이브부터 판은 이어진다(엔딩 뒤 끝없는 구간). HUD 웨이브 번호는 금색. 45웨이브 B3, 55웨이브부터 회차 2 보스 |
- 엔딩은 한 판에 한 번. 회차 2 이상의 B5(85, 135 ...)를 잡으면 짧은 판: 세상 멈춤 없이 물결, 시각만 새벽으로, 큰 글귀 `t_again`("또 아침").
- `/gave 웨이브` 로 건너뛴 판(Records.skipped)은 엔딩 기록에 skipped 를 단다.
- 시각 연출은 세계 시각(`world.setTime`)만 바꾼다. 안개는 따로 도는 안개 시계(Fog)라 영향이 없다. 쉬는 시간이 끝나면 13000 으로 되돌린다(감독 reset 도 13000).

### 11.2 Species 와 이름
- 보스도 `Species` 행이다(Gabe 가 sp 로 모델 `gabe/bx`, 소리 `gabe.bx.*`, 글귀 `name_bx`, 아이콘 키를 정하므로). `tools/gen_species.py` 에 bestiary 와 따로 `BOSSES` 표를 두고 55(앞으로 155)종 뒤에 붙인다(19절 요청):
```
B1("산더미 게이브", 10, 5, Band.GROUND, Spawn.DERIVED, 18500, 6, 0, Role.BOSS),
B2("하늘 덮는 게이브", 20, 5, Band.SKY, Spawn.DERIVED, 20000, 22, 0, Role.BOSS),
B3("에워싸는 게이브", 30, 5, Band.GROUND, Spawn.DERIVED, 32000, 36, 0, Role.BOSS),
B4("지평선 게이브", 40, 5, Band.SKY, Spawn.DERIVED, 29000, 20, 0, Role.BOSS),
B5("모두의 게이브", 50, 5, Band.GROUND, Spawn.DERIVED, 56000, 30, 0, Role.BOSS);
```
  - `Spawn.DERIVED`: 감독 대기열이 내지 않는다(`spawnable` 이 뺌). 다른 게이브를 고르는 종들(G27, G34, G54, G47 은 PLACED, DERIVED, RING 아닌 것을 뺌)이 저절로 보스를 건드리지 않는다.
  - 새 `Role.BOSS`(Role.java, 엔진 담당): 종 묶음 역할에 없으므로 묶음에 안 든다. tier 가 10 이상이라 '등급 1~8 늘 들어감'에도 안 든다. 보스인지 물을 때 `sp.is(Role.BOSS)`.
  - hp 칸은 H[b](4.1절), cost 는 몸 디스플레이 수, reward 0.
- 키는 소문자 `b1`..`b5`: 모델 `gave:gabe/b1`, 소리 `gave:gabe.b1.step`, 글귀 `name_b1`, `cause_b1_slam`, 아이콘 `build/gabe/icons/b1.png` → `ic_l_b1`.
- `tools/make_gabe.py` 의 종 스크립트 이름 정규식 `SPF = ^g\d\d$` 를 `^(g\d{2,3}|b[1-5])$` 로(새 종 G100~ 도 같이 됨, 19절 요청). 보스는 bestiary 에 없으니 `info = {}` 로 굽는다(키트는 info 를 거의 안 씀).

### 11.3 Boss 바탕(꼴)
```java
package kr.gave.mob.boss;

public abstract class Boss extends Gabe {
    public final int cycle;                 // 회차(10~45: 1, 55~95: 2 ...). BossDirector 가 소환 직전에 정해 둔 값을 읽음
    public int phase = 1;                   // 단계(1부터)
    protected final double[] cuts;          // 단계 문턱(체력 비율, 큰 것부터), 예 {0.60, 0.25}
    protected final List<double[]> hitNow = new ArrayList<>();   // 이번 틱 맞는 구(틱마다 다시 채움, spheres() 가 그대로 돌려줌)
    protected final List<Region> regions = new ArrayList<>();    // 부위: 이름, 구 번호 범위, 받는 배율, 부위 체력(끊김 셈), 끊김 반응(Body.Part 와 다른 것)
    protected final Threat threat = new Threat();                // 6.2절(Boss 안 작은 클래스여도 됨)
    protected boolean intro = true, dying, transition, enraged;
    protected int fightTicks;

    // 보스 클래스 생성자는 Species.create 의 리플렉션 꼴 그대로 (Game, Species): public B1(Game g, Species s) { super(g, s, new double[] {0.60, 0.25}); hover = 5.5; }
    protected Boss(Game game, Species sp, double[] cuts) {
        super(game, sp);
        this.cycle = game.director.boss.pendingCycle(); this.cuts = cuts;
        noRules = noBite = noMutate = noPush = true;  // 판 규칙, 물어뜯기, 변함, 밀어내기에서 빠짐
        noReward = true; reward = 0;                  // 보상은 BossDirector 가 모두에게
        ghost = true; ragKick = 0.15; ragRods = 0;    // 거대한 몸: 벽 무시, 무거운 사체
        untargetable = true;                          // 등장 연출 동안
    }

    @Override public final void tick() {
        if (dying) { dyingTick(); return; }
        if (intro) { introTick(); return; }
        fightTicks++; threat.tick(this); refreshSpheres(); checkPhase(); act();
    }
    protected abstract void introTick();   // 끝나면 intro = false, untargetable = false
    protected abstract void act();         // 공격 칸 돌리기, 걷기
    protected abstract void refreshSpheres();
    protected abstract void dyingTick();   // 끝에서 super.die(lastHit)
    public abstract void victory();        // 3.5절(전멸)

    @Override public List<double[]> spheres() { return hitNow; }
    @Override public void lure(Vector at, int ticks) { }         // 끌리지 않음(딸랑이, 거미줄, 판 끝 모임)
    @Override public boolean damage(Damage d) { ... }            // 11.6절
    @Override public void die(Damage d) { if (!dying) startDying(d); }   // 바로 죽지 않고 죽음 연출부터

    protected void hitBoss(Player p, double dmg, String cause) {
        double k = Math.min(2.0, 1 + 0.2 * (cycle - 1)) * (enraged ? 1.25 : 1.0);
        game.players.hurt(p, k * dmg / game.director.dmgMul(), this, cause);
    }
}
```
- 공격 하나 = 이름, 단계 범위, 다시 쓰기(틱), 예고(틱), 표적 고르는 법, ★ 여부, 시작, 틱, 끝 메서드. 공격 칸(6.2절)이 돌며 다시 쓰기가 찬 것 가운데 고른다(같은 것 연달아 두 번 금지, 쓸 수 있는 것이 없으면 걷기).
- 회차, 화남 배율: 예고 x 0.9^(c-1)(0.6 까지, 12틱 아래 금지), 다시 쓰기 x 0.85^(c-1)(0.55 까지) x 화남 0.7.
- 종 코드 계약(엔진이 던짐을 잡음)은 그대로다. 보스가 던지면 엔진이 그 보스를 치운다: BossDirector 는 다음 틱에 보스가 사라졌으면 물결 없이 웨이브를 보통으로 돌리고(남은 떼가 끝나면 끝), '[판] 보스 오류' 를 남긴다.

### 11.4 BossDirector(감독 연결)
- 감독이 만든다: `Director.boss = new BossDirector(game)`(19절 요청, Director 생성자). 공개 메서드:

| 메서드 | 누가 부름 | 일 |
|---|---|---|
| `isBossWave(n)`, `bossFor(n)`, `cycleOf(n)` | 감독, HUD, Music | 3.1절 |
| `pendingCycle()` | 보스 생성자 | 지금 놓는 보스의 회차(시험 훅 '소환' 의 회차 인자도 여기로) |
| `adjust(Plan p)` | 감독 `plan(n)` 끝 | 3.3절(총량 x0.5, 빼는 것들) |
| `beginWave(n)` | 감독 `beginWave` 끝 | 보스 소환, announceUntil 을 INTRO 만큼 미룸(감독에 `delayAnnounce(ticks)` 요청), 레터박스, 제목, 브금 |
| `tick(now)` | 감독 `tick()` 첫머리 | 등장, 떼 경배, 보충, 사람 수 다시 재기, 물결, 엔딩 차례 |
| `aliveScale()` | 감독 `releaseBatch` | 보스 웨이브면 0.6, 아니면 1 |
| `reserve()` | 감독 `reserve()` | 보스 웨이브면 20 |
| `blocking()` | 감독 `waveDone()` 첫머리 | 보스가 살아 있거나 물결 중이면 true(웨이브 안 끝남), 막힘 정리도 막음 |
| `beginBreak(n)` | 감독 `beginBreak` | 남은 보스 조용히 치움(시험 건너뛰기), HUD 틀 끔, 시각 되돌림, 다음이 보스면 7.3절 |
| `breakTicks(기본)` | 감독 `breakTicks()` | 엔딩 뒤 쉬는 시간이면 1200 |
| `gameOver()` | 감독 `gameOver()` 첫머리 | 보스 `victory()` |
| `reset()` | 감독 `reset()` | 모두 지움, 엔딩 표시 풂 |
| `frame()` | HUD | 7.1절 |
| `active()`, `boss()` | Music, HUD, 상태 | 보스 웨이브 중인가, 지금 보스 |
| `status()` | 감독 `status()` | `boss=B1:0.73:p2`(없으면 `boss=-`, 대본 until 이 읽음) |
| `test(p, a)` | 감독 `test()` 가 '보스' 를 넘김 | 18절 |
- 보스 놓기: `game.mobs.spawn(Species.Bx, at, false)` → null 이면(예산, 예외) 20틱 뒤 다시, 5번 실패면 보통 웨이브로. 보스는 감독 `fromDirector` 에 넣지 않는다(떼 수 셈, 소리 층 셈에서 빠짐). maxHp, hp 는 4.1절로 BossDirector 가 넣는다(감독 hpMul 을 곱하지 않음).

### 11.5 몸(키트, 부품, 크기)
- 크기: 모델은 키트 틀(-16..32 px, 가운데에서 약 ±1.5블록) 안에서 보통 크기로 굽고 Java 에서 키운다: 몸 전체 `body.scale(s, 틱)`, 부품 하나는 `Part.local` 행렬의 배율. 모델 하나가 틀을 넘을 때만 `k.model(shrink=0.5)`.
- 배율 셈(Body.Part.rig): 몸을 따르는 부품(`follow = true`)은 몸 틀(몸 배율 포함) 위에 `local` 이 곱해진다. 그래서 그 부품의 `local` 자리와 배율은 '몸 배율 1' 단위로 적는다(세계 크기 = 몸 배율 x local 배율). 세계 축 부품(`follow = false`)은 몸 배율이 안 곱해지고 블록 단위다. **보스 절 모델 표의 '배율'은 세계 크기 배율**이다: 몸을 따르는 부품이면 `local 배율 = 표의 배율 / 몸 배율` 로 넣는다.
- 면 한도: 상태 모델 하나 400(`budget`), 모델 하나 틴트 칸 80. 거대한 몸은 부품(디스플레이) 여럿으로 나눈다.
- 거대한 막대기의 펄럭임: 프레임 접기는 자세 사이를 보간하지 않으므로 긴 주기(60~120틱)에 자세 4~6장이면 뚝뚝 끊겨 보인다. 그래서 **큰 흔들림은 부품 보간**(막대기 하나 = 부품 하나, `Part.pose(행렬, 20~30틱)` 으로 뿌리 축 회전), **막대기 안 물결은 프레임 접기**(자세 4, 주기 20, 폭 작게)로 나눈다.
- 컬링: 닻이 있는 보스는 `Body.of(this, "gabe/bx", 폭, 높이)` 에 몸 전체 크기를 준다(넘으면 화면 끝에서 사라짐). 부품은 닻의 폭, 높이를 이어받는다. 멀리 서거나 둘레를 도는 보스(B3, B4)는 **가운데 빈 닻**(`Body.carrier`, 컬링 없음)을 중앙 원 가운데에 두고 몸을 모두 세계 축 부품(`part.follow = false`, `local` 에 중심에서의 자리)으로 옮긴다: 서버 추적 거리(display 128) 안에 늘 들고, 사람이 어디 있든 보인다.
- 보이는 거리: `body.viewRange(3.0~4.0)`(192~256블록). 안개 끝(기본 64, 맑음 160)보다 멀면 어차피 안 보인다.
- 밝기는 엔진 기본(block 10, sky 10). 15 로 빛나게 하지 않는다.
- 3블록 안 사람 얼굴은 셰이더가 거리로 고르므로 거대한 얼굴에도 저절로 된다(얼굴 면 3블록 안에 들어가면 땀구멍이 주먹만 함).
- 아이템 디스플레이는 모델을 y 로 반 바퀴 돌려 그린다(엔진이 붙임). 모델 앞(+Z) = 몸 앞.
- 사체 상태 `<상태>.c` 는 키트가 저절로 굽는다. 보스 막대기는 부품이라 `k.model(rag=False)` 로 꺼도 된다(11.7절).

### 11.6 맞는 구, 부위, 약점, 받는 피해
- 구는 틱마다 한 번 계산해 `hitNow` 에 담는다(`spheres()` 는 탄 하나마다 불리므로 새로 만들지 않는다). 세계 자리 = pos + (몸 회전) x (모델 자리 x 배율). 몸 회전은 Body 와 같게: rotateY(-yaw) → rotateX(pitch) → rotateZ(roll).
- 받는 피해(`damage(d)`):
  1. 받는 것: `d.by() != null` 이고 종류가 BULLET, PELLET, SNIPER, EXPLOSION, FIRE 이고 `d.how()` 가 'g' + 숫자로 시작하지 않는 것(다른 종 장치 빼기: G05 즙 같은 maxHp 비례 피해). 시험 훅 피해(how 가 test 로 시작)는 받는다. BITE, OTHER 는 버린다.
  2. 맞은 점 `d.at()`(총은 엔진이 핑 되돌림을 푼 탄착점, 폭발과 불은 `center(o)` 가 준 점: big 요청 뒤에는 폭발점에서 가장 가까운 구 표면)에서 가장 가까운 구 → 부위.
  3. 실제 양 = 양 x 부위 배율 x 약점 배율 x (B4 배움) x (전이 0.25).
  4. 부위 체력이 있으면 그 셈에서도 깎는다(끊기면 부위 반응). **부위 피해도 늘 보스 체력에서 깎인다**(부위 체력은 '끊김 셈'일 뿐 막대에 따로 안 보임).
  5. 단계 문턱 보호(4.6절), `game.mobs.onHurt(this, d, 실제 양)`, 체력 0 이면 `die(d)` → 죽음 연출.
  6. 약점이면 쏜 사람에게 6.3절 신호. 0.5 배 아래면 안 먹힘 신호.
- 폭발과 불이 거대한 몸에 닿게: 엔진 `Mobs.inRadius`, `center` 가 지금은 몸 중심(pos) 하나만 본다. 19절 요청(`Gabe.big`): big 이면 구마다 '구 표면이 반경 안'으로 들고, center 는 그 틱 물음 자리에서 가장 가까운 구 표면 점. 그 전까지는 보스가 수류탄, 화염병, 화염방사기(wpn12)에 거의 안 맞는다.

### 11.7 래그돌 사체(거대)
- 엔진 래그돌이 닻 + 부품을 조각으로 굴린다. 한 구에 조각 `maxPieces` 12(닻 + 부품 11, 붙인 차례). **사체로 남길 부품을 먼저 붙인다.** 넘는 부품은 그 자리에서 줄어들어 사라진다.
- 거대한 상자도 같은 물리로 쓰러진다(충격 무시할 만큼 무거움: `ragKick` 0.05~0.2). 흐물 막대기 사슬(공용 마디 모델)은 닻 모델의 막대기만 쓰므로 보스는 `ragRods = 0` 으로 둔다(큰 막대기는 부품 조각으로 굴러 쓰러짐).
- 보스 사체는 쉬는 시간 내내 남기고 싶다: 19절 요청 `Gabe.ragHold`(틱, 기본 -1 = 설정 settleSeconds). 보스는 400~600.
- 보스 사체를 다른 종이 먹지 않게(G11 시체 뜯기, G12 얼굴 꿰기, G19 방패): 19절 요청 `Mobs.corpses()` 가 Role.BOSS 사체를 빼고 준다.
- 보스마다 죽음 연출 끝에 `super.die(d)`(그 전에 사체로 안 남길 부품은 `Part.remove()`).

### 11.11 구현된 바탕 API(boss_infra, 2026-11-12: 보스를 만드는 사람은 여기부터)

바탕은 진짜 트리에 있다: `kr.gave.mob.boss.Boss`(보스 바탕), `BossDirector`(보스 웨이브 감독, `game.director.bosses`), `Tele`(바닥 예고), `Terrain`(맵 연출, 11.12절), `Ward`(지킬 것, 11.13절), `Dummy`(시험용 빈 보스이자 본보기). 감독 고리(`Director.BossHook`), HUD 보스 칸, 브금 켜고 끄기, 기록은 이미 이어져 있다. 보스 구현자는 **팩 스크립트 하나와 클래스 하나**만 만든다.

**보스 하나를 만드는 순서**
1. 팩 `tools/gabe/sp/b1.py`: 모델과 상태, 소리, 아이콘(`k.icon`), 글귀(`phrases()` → `data/phrases/B1.json`: `bs_sub_b1`, `bs_b1_p2`, `bs_b1_p3`, `cause_b1_*`). 이름 `name_b1` 과 등장 큰 제목 `t_b1` 은 make_hud 가 도감(bestiary) 이름으로 저절로 그린다(글귀 파일에 `t_b1` 을 적으면 그 글). 공용 예고 판 모델 다섯(아래 '예고')과 공용 소리(`boss.wave`, `boss.weak`, `boss.immune`, `boss.next`)는 b1.py 몫이다. `make_gabe.py` → `make_hud.py` → `compile_wip.py --name hud --promote`.
2. 클래스 `kr.gave.mob.sp.B1 extends kr.gave.mob.boss.Boss`(생성자 `(Game, Species)`, 아래 꼴). 클래스가 생기면 `Species.B1.implemented()` 가 참이 되어 10웨이브에 저절로 나온다(없는 보스의 웨이브는 보통 웨이브).
3. 시험: `/gave 시험 보스 x 소환 B1`(웨이브 중 바로) 또는 `gave 웨이브 10`. 대본 틀은 `tools/scenarios/boss_infra_flow.json`(보스 웨이브 끝까지), `boss_infra_ending.json`(35웨이브 엔딩), `boss_infra_map.json`(예고, 땅). 빈 보스로 흐름만 볼 때는 `/gave 시험 보스 x 빈보스 on`.

```java
package kr.gave.mob.sp;

public final class B1 extends Boss {
    private final Region back;

    public B1(Game g, Species s) {
        super(g, s, new double[] {0.60, 0.25});          // 단계 문턱(체력 비율, 큰 것부터): 단계 수 = 길이 + 1
        hover = 5.5; radius = 3.4; baseSpeed = 0.06;      // Gabe 필드 그대로
        back = region("back", 3.0); back.weak = true;     // 약점 부위(맞히면 '칭' + 금색 적중)
        Region rod = region("rod0", 1.0); rod.hpFrac = 0.04; rod.onCut = r -> body.look.on.add("cut_0");   // 부위 체력(끊김 셈)
        attacks.add(new Attack("slam", 1, 2, 180, 32, Pick.CLUSTER, true) {   // 이름, 단계 from..to, 다시 쓰기, 예고 틱, 표적, ★
            Tele tl;
            @Override protected void start() { tl = disc(aim, 6, tellTicks); sfx("gabe.b1.inhale", Sound.ENTITY_WARDEN_SONIC_CHARGE, 1f, 0.6f, 64); }
            @Override protected boolean step() {              // 매 틱, 끝났으면 true
                if (!told()) return false;                    // 예고가 다 찰 때까지
                for (Player p : caught(tl, 0.3)) { hitBoss(p, 40, "cause_b1_slam"); game.players.root(p, 20, "boss"); }
                quake(tl.at, 24, 0.9);
                mend(pit(tl.at, 6, 1, 6), 30, 200);           // 맵 활용: 엎어진 자리가 10초 꺼짐
                return true;
            }
        });
    }
    @Override protected void build() { body = Body.of(this, "gabe/b1", 12f, 11f); body.scale(4.5f, 0); body.viewRange(3.0f); }
    @Override protected void refreshSpheres() { sphere(main, pos.getX(), pos.getY(), pos.getZ(), 3.4); double[] b = world(0, 0.2, -0.7, 4.5); sphere(back, b[0], b[1], b[2], 1.2); }
    @Override protected void act() { seek(crowdCenter().setY(pos.getY()), speed()); runAttacks(); }
    @Override protected void introStep(int t) { /* 걸어 나옴. 소리, 하늘, 제목, 그림자는 바탕이 침 */ }
    @Override protected void dyingStep(int t) { /* 머리가 넘어감 */ }
}
```

**Boss 가 스스로 하는 것**(덮어쓰지 않는다): `tick()`(final: 예고 돌리기 → 등장, 죽음, 멈춤, 싸움으로 나눔), `damage()`(받는 피해 규칙 11.6절: 부위 배율, 약점 신호, 단계 문턱 보호, 위협 표), `die()`(바로 안 죽고 죽음 연출부터), `lure()`(끌리지 않음), 생성자의 기본값(`noRules`, `noBite`, `noMutate`, `noPush`, `noReward`, `ghost`, `big`, `ragHold` 500, `ragKick` 0.15, `ragRods` 0, 등장 동안 `untargetable`).

| 무엇 | Boss 의 이름 | 뜻 |

- **되돌림 기록**: 바꾸는 칸마다 원래 블록을 처음 건드릴 때 한 번 적는다(메모리 + `plugins/Gave/boss_terrain.journal`). 보스 감독이 쉬는 시간이 시작될 때, 새 웨이브가 시작될 때, 판이 바뀔 때(시작, 끝), 보스가 엉뚱하게 사라졌을 때 모두 되돌린다. 서버가 싸움 도중 꺼졌으면 다음에 켠 뒤 첫 틱에 파일을 읽어 되돌린다. 보스는 죽을 때 따로 되돌릴 필요가 없다(쉬는 시간 전까지 남기고 싶지 않으면 `mend`).
- **걷기 격자**: 블록이 바뀌면 바뀜이 잦아들고 3틱 뒤(연출이 길면 20틱마다) `Plaza.scan` 과 `Flow.rescan` 을 한 번 돌린다(게임 안에서 8~12ms). 그래서 한 틱에 여러 번 조금씩 바꾸기보다 한 번에 바꾼다.
- **손대지 않는 곳**: 보급 상자 둘레 3.6블록, 살아 있는 보급 상자 둘레 2.5블록, 지킬 것(Ward) 둘레, 경기장 밖(R 96), 바닥 아래 3블록보다 깊은 곳, 바닥 위 24블록보다 높은 곳. 한 판에 기록하는 칸은 24000 까지.
- 블록은 물리 없이 바뀐다(자갈이 떨어지지 않음). 블록이 사람 몸에 겹치게 솟거나 메워지면 그 사람을 그 위로 올린다. 사람을 밀어내고 싶으면 솟기 전에 `knock` 으로.

### 11.13 지킬 것(Ward: 트럭 같은 사람 아닌 표적을 위한 자리)

판 구조가 바뀌는 중이다(중앙 상점이 체력 있는 트럭, docs/모듈/원정.md). 트럭은 다른 작업자가 만들고, 보스 쪽에는 그것을 표적으로 삼는 자리만 있다.
- 트럭을 만드는 모듈: `kr.gave.mob.boss.Ward`(`key()`, `pos()`, `radius()`, `alive()`, `hurt(값, 보스, 원인)`)를 이어받아 `game.director.bosses.guard(ward)` 로 올리고, 없어질 때 `unguard(ward)`.
- 보스: 공격의 표적을 `Pick.WARD` 로 두면 가장 가까운 지킬 것을 겨눈다(`Attack.ward`, `aim` 은 그 자리. 올라온 것이 없으면 TOP 으로 사람). `ward()`, `caughtWards(예고, 여유)`(예고 안에 걸친 것), `hitWard(w, 값, 원인)`(보스 표 값 x 회차 x 화남: 사람 피해와 같은 단위. 체력과 판 끝은 트럭 쪽이 정함).
- 맵 연출은 지킬 것 둘레(반지름 + 1.5블록) 땅을 바꾸지 않는다.
- 지금 올라온 지킬 것은 없다(트럭이 생기기 전): 보스는 사람만 노린다. 게임 안 확인 없음(컴파일만).

## 17. 55웨이브부터(회차 2, 3 ...)
- 같은 차례로 다시 나온다(55 B1, 65 B2, 75 B4, 85 B5, 95 B3, 105 B1 ...). 회차 c = (보스 웨이브 번호 k) / 5 + 1(3.1절).
- 세짐:

| 항목 | 회차 c |
|---|---|
| 체력 | 4.1절(D(w) 가 웨이브로 커지고 C(c) = 1 + 0.25(c - 1)). 같은 보스 지난 회차 체력의 1.25배 아래로는 안 내려감 |
| 피해 | x(1 + 0.2(c - 1)), 2배까지 |
| 예고 | x0.9^(c - 1), 0.6배까지(12틱 아래 금지) |
| 다시 쓰기 | x0.85^(c - 1), 0.55배까지 |
| 졸개 수 | x(1 + 0.3(c - 1)) |
| c = 2 덤 기술 | B1: 2단계부터 무더기 얼굴을 위로 던져 얼굴비(B2 꼴, 초당 2, 8). B2: 내려앉기 다리가 꽂힐 때마다 그 자리에서 흰 파도 고리(뛰어 넘기). B3: 노래 멈춤 동안 술래 눈에서 노란 빛 자리 하나가 고리 안을 쓸고 감(B4 변이). B4: 두 눈이 함께 뜨인 동안 움직이면 게이지 2배(B3 노래 멈춤 규칙). B5: 1단계부터 허리 고리가 풀려 있음 |
| c >= 3 | 단계 문턱은 그대로 두고 처음부터 마지막 단계 기술까지 모두 씀(화난 채로 옴, 이름 빨강) |
- 엔딩은 한 판에 한 번(10절). 회차 2 이상 B5 는 '또 아침'.
- 41웨이브부터 쌓이는 감독 변이(burst, riders, split, mutfast, elite, swift, thick, horde)는 보스 떼에 그대로 걸리고 보스 자신에게는 안 걸린다(swift, thick 도 보스는 4절, 6절 공식만).

## 20. 정할 것, 확인 못 한 것

**2026-11-12 바탕 구현 뒤**(boss_infra): 바탕은 시험용 빈 보스로 게임 안에서 돌려 봤다(10웨이브 보스 웨이브 끝까지, 35웨이브 엔딩과 36웨이브로 이어짐, 맵 연출 도구). 아래 옛 항목 가운데 '하나도 돌려 보지 않았다' 는 보스 다섯의 행동과 모델에만 남는다. 바탕에서 확인 못 한 것: 두 사람 이상(표적 고르기, 공격 칸 수, 사람 수에 따른 체력 다시 재기), 회차 2 이상과 화남의 실제 싸움, 전멸 승리 연출, 진짜 총으로 약점과 부위 끊기(빈 보스 코 약점은 권총으로 맞음: '칭' 소리 사건이 팩에 없어 바닐라 대체), 음소거 클라라 소리 전부(서버 기록의 곡 차례만 봄), 30명 성능, 서버를 싸움 도중 끈 뒤의 땅 되돌림, 지킬 것(Ward).
- 모두 설계다. 게임 안에서 하나도 돌려 보지 않았다(boss_d 는 서버와 클라를 돌리지 않음).
- 체력 표는 모의(balance_sim, 숙련 0.7)의 1인 화력과 어림(명중 0.8, 몰두 f, 약점 덤 1.15)에서 나왔다. 모의는 떼를 쏘는 모의라 보스에 대한 실제 명중, 몰두는 모른다. 첫 시험 뒤 H 를 고친다.
- bal12 가 게이브 피해와 수를, wpn12 가 무기를 지금 바꾸고 있다. 보스 피해는 dmgMul 과 떨어져 있어 영향이 없지만 체력은 화력에 달려 있다(4.5절 보정 권장).
- 거대한 크기(배율 16~32)의 키트 얼굴, 3블록 안 얼굴, 래그돌 강체, 프레임 접기가 어떻게 보이는지 확인 못 했다. 래그돌 조각 상자가 수십 블록이면 굳는 판정(빠르기 0.03)이 늦을 수 있다.
- 뛰어 넘기 판정은 서버가 보는 땅 닿음(`isOnGround`)이다. 핑이 큰 사람은 늦게 보일 수 있어 파도가 지나는 틱 앞뒤 2틱을 봐 준다.
