## 요약

- **진단(확인)**: 55종 가운데 21종이 "떠다니는 0.6~1.0 블록 얼굴 + 펄럭이는 엔드 막대기 둘"이고 막대기 방향만 다르다(옆, 위, 아래, 앞뒤). 막대기가 실루엣의 주인인 G16(해파리 다리 넷), G49(땅 촉수 셋)까지 23종. 막대기 굵기 0.08~0.12 블록이라 20블록 밖에서는 화면 1~2 화소쯤(어림)이고, 남는 것은 같은 얼굴 상자뿐이다(게임 사진에서도 막대기는 회색 실선). 얼굴 크기도 31종이 0.6~1.0 블록에 몰려 있다.
- **처방**: 20종을 바꾼다. 실루엣을 바꾸는 13종(G05, G06, G09, G10, G12, G14, G15, G16, G32, G36, G41, G46, G51)과 거대하게 키우는 7종(G18, G27, G28, G34, G39, G42, G43). G01(사용자가 처음 그린 가오리)은 그대로.
- **결과(시안 셈)**: 촉수형 21 → 6, 가장 큰 갈래 21 → 6. 갈래 12 → 16. 얼굴(머리)이 1.5 블록 넘는 종 3 → 7(공중 넷: G28 4블록, G39, G42, G43).
- **원칙**: 막대기를 지우지 않고 **쓰임을 바꾼다**(다리, 인형 줄, 우산살, 새장 창살, 등줄기와 갈비, 꼬리, 목도리 주름). 원형 DNA(펄럭이는 엔드 막대기 둘)는 남기되 짧게 더듬이, 꼬리, 줄, 갈고리 자리로 내려 실루엣의 주인이 몸통이 되게 한다. 몸통은 살(flesh), 뼈(bone), 사마귀 살 같은 다른 재질로.
- **계약**: 모델 이름, 상태, 부위, 소리, 글귀, 덮개는 하나도 안 바꾼다. 실루엣 13종은 팩 스크립트 `build()` 만 고치면 된다(맞는 구를 넓히는 Java 한 줄은 선택). 거대 7종은 Java 상수 몇 개(5절 표)가 같이 바뀐다.
- **시안 확인(확인)**: `build/look_audit/proto.py` 로 20종 새 모델을 키트로 메모리에서 지어 보니 모두 굽기 검사(`build_files`)를 지나고 상태 모델마다 면 400 이하, 모델 틴트 칸 80 이하였다(G34 는 지금과 같은 80). 그림은 빛, 셰이더, 안개 없는 정사영이라 게임 화면과 같지 않다.

## 4. 종마다 새 모델(키트 함수 수준)

좌표는 블록, 모델 가운데(몸 자리 = 맞는 구 가운데)가 0, +Y 위, +Z 앞(얼굴), +X 는 게이브 자신의 왼쪽. 수치는 시안(`proto.py` 의 `p_gxx`) 값이고 미리보기를 보며 다듬는다. "DNA" 는 원형 DNA(펄럭이는 엔드 막대기 둘). 맞는 구 판정은 구 반지름 + 0.25(`Mobs.R_BULLET`, 확인)라, 가운데에서 `radius + 0.25` 안에 든 몸은 Java 를 안 고쳐도 맞는다.

### 4.1 공통 키트 함정(시안 굽기에서 확인)

1. 곧게 아래(0, -1, 0)나 위로 뻗는 막대기는 기본 `toward=(0, 1, 0)` 과 나란해 `ValueError("toward 가 dir 과 나란함")`. 기둥, 손잡이, 줄기는 `toward=(0, 0, 1)`.
2. 사슬 이음점(마지막 마디 앞까지)이 모델 틀(가운데에서 1.5 / shrink 블록) 밖이면 굽기 실패. 몸이 뒤로 긴 쥐(G14), 상어 뼈(G46), 접힌 우산(G16)은 `shrink=0.75` 가 필요했다. 마디 상자는 이음점에서 틀 끝까지 세워 들어가야 하므로(가운데 이음점이면 1.5 / shrink 블록까지) 땅까지 닿는 다리, 줄기는 `segs=2` 로 나눈다.
3. `s.box(..., {면: 텍스처})` 에 사전을 줄 때 사전에 없는 면은 `faces=(...)` 로 빼야 한다(빼지 않으면 `KeyError`).
4. 면 400 의 대부분은 자세 면이다. 구조 막대기(다리, 기둥, 창살, 갈비)는 `wave=None`(자세 없음, 막대기 하나 5~15면), 펄럭이는 DNA 막대기는 `segs=2, poses=4`(둘에 72면). 지금 많은 종이 DNA 막대기를 8자세 3마디(둘에 208면)로 쓰고 있어 그것만 줄여도 몸통 지을 자리가 난다.
5. 사체(래그돌, 추측 포함): 길이 0.3 넘는 펄럭 막대기는 흐물 막대기로 떨어져 나간다. 땅까지 닿는 줄기, 삼각대 다리처럼 **가만히 있는** 긴 막대기는 `rag=True` 로 흐물 막대기로 빼면 사체 몸 상자가 머리 크기로 줄어 "바로 선 채 굳는" 일(래그돌.md 한계)이 줄 것이다. 반대로 끝에 손으로 짠 판이 붙은 막대기(G32 주둥이)는 `rag=False`(흐물거리면 판만 허공에 남음).
6. 새 텍스처 이름은 `_n`, `_s`, `_e` 로 끝내지 않는다(키트가 바꾸지만 id 를 글자로 이어 붙이지 말 것, 종작성법 끝 절).

### 4.3 거대하게 키우는 7종

거대화는 **팩에서 블록 좌표를 키우고 `shrink` 로 틀에 맞춘다**(엔진이 `Look.scale = 1 / shrink` 를 곱함, 래그돌 상자도 키트가 블록 단위로 적으므로 따라감: 확인). Java `body.scale` 로 키우지 않는 까닭(확인): G05, G09, G19, G31 처럼 `body.scale` 을 연출에 쓰는 종이 있고, G28 그림자, G42 알주머니, G43 빛 자리 부품은 `follow = false` 라 `body.scale` 을 안 따른다. 맞는 구, 입이나 눈 자리 같은 Java 상수는 5절 표대로 같이 바꾼다.

## 6. 바꾸면 안 되는 계약

### 6.1 모든 종
- 모델 이름(아이템 정의 `gave:gabe/<모델>`), 상태 이름(`custom_model_data.strings[0]`), 기본 상태, 부위 이름(`on:<부위>`), 소리 사건(`gave:gabe.<종>.<이름>`)과 자막 키, 글귀 키(`cause_gxx`, `notice_gxx_*`), 덮개 키. 상태를 새로 만들어도 Java 가 부르지 않으면 쓰이지 않는다.
- `k.model(...)` 의 `poses`, `period` 는 Java 박자(소리 타이밍)와 묶인 종이 있다(G15, G34). 아래 표의 '박자'를 지킨다.

- 효과(빛, 줄, 탄)는 지금 부품 그대로(발광 테두리, 블록 디스플레이 상자 하나 금지 원칙 유지). 새 창살, 손바닥, 꼭지 판은 텍스처 모델 요소다.
