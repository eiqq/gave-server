# 게이브 모델과 팩(tools/make_gabe.py, tools/gabe/kit.py, tools/gabe/sp/*.py, pack_fx 게이브 셰이더, kr.gave.mob.Look)

## 얼굴 그림
- 원본 `ref/_Gave_skin.png`(64x64). 얼굴 앞 (8,8)-(16,16) + 모자 층 (40,8)-(48,16). 연한 분홍 살(ffe2db 근처), 적갈색(591b1b, 613939) 실눈 웃음 줄 두 줄, 위 모서리 적갈색 덩어리(모자 층), 흰 반짝임(f6f1f1), 점 입(421414), 볼 홍조(ffd3c7). 뒤통수, 옆면도 스킨에 있다.
- 파생 얼굴은 32x32 로 손맛 나게(픽셀 느낌 유지) 프로그램으로 그린다: 실눈(기본), 반쯤 뜬 눈, 다 뜬 눈(동공, 반짝임), 핏발 선 흰자 바늘 동공, 입 찢어짐(가로로 귀까지), 눈물, 무표정(웃음 지움), 금빛 홍조, 바늘땀 이음선, 세로 반쪽, 뒤집힌 얼굴, 이빨 고리 입, 벌집 구멍 입 등. 신호를 픽셀 하나에 걸지 않는다(멀리서도 읽히게 굵게).
- 3블록 안에서 바뀌는 사람 같은 얼굴(128x128, 같은 이목구비): 부드럽게 키운 뒤 살결 잡음, 솜털, 땀구멍, 젖은 눈꺼풀 반사, 점 입 안의 사람 이. 무섭게, 하지만 피 철철 고어는 아님.
- 텍스처는 `assets/gave/textures/item/gabe/...`(26.3 아이템 모델 텍스처는 items 아틀라스, 쓰지 않는 큰 그림은 넣지 않는다). 엔드 막대기는 바닐라 `minecraft:block/end_rod` 를 쓰지 말고(아틀라스 섞임 금지) 같은 생김새를 `gave:item/gabe/rod` 로 다시 그린다.

## 모델 키트(kit.py)
- 요소 좌표는 -16..32, 회전은 26.3 오일러 x,y,z(각도 제한 없음, Rz Ry Rx). 면 texture 는 `#변수` 로만. 아이템 디스플레이는 모델을 y 로 반 바퀴 돌려 그린다(앞 = 모델 -Z 쪽 north 면이 디스플레이 +Z 를 봄, 기억: mc-263-model-format).
- 부품: 얼굴 상자(먼 면 + 가까운 면 겹쳐 둠), 엔드 막대기 사슬(마디 수, 길이, 굵기), 쇠사슬, 거미줄 막, 분홍 살 띠, 뼈 이빨 고리 등.
- 펄럭임: 자세 N장(4~8)을 굽는다. 막대기 사슬은 뿌리에서 끝으로 위상이 늦는 파도(마디마다 각도 = A sin(2pi(k/N) - i*phi)). 지금 프레임이 아닌 면은 셰이더가 접어 숨긴다.
- 틴트 역할: 모델의 요소마다 tintindex 를 주고, 그 칸이 무슨 역할인지(far 얼굴, near 얼굴, 자세 k, 부위 이름 켜기, 실눈 뜸 오버레이, 변이 1 오버레이(입 찢어짐), 변이 2 부위(막대기 둘 더, 자세 k 와 함께), 늘 보임)를 모델별 표로 `assets/gave/gabe_looks.json` 에 쓴다. 아이템 정의의 tints 는 칸마다 `minecraft:custom_model_data` 색 칸을 가리킨다.
- 모든 게이브 모델은 실눈 뜸 오버레이와 변이 1(입 찢어짐), 변이 2(막대기 둘 더) 부위를 기본으로 가진다(키트가 자동으로 붙임, 종이 끌 수 있음). 원형 DNA: 어떤 종이든 어딘가에 펄럭이는 엔드 막대기 둘이 있다.
- 아이템 정의 `assets/gave/items/gabe/<종>.json`: `select` on `custom_model_data` strings[0] 으로 상태별 모델, 기본은 "" 상태. `hand_animation_on_swap: false`.
- HUD 아이콘: 종마다 `build/gabe/icons/<종>.png`(64x64, 얼굴 정면 또는 실루엣, 투명 배경). make_hud 가 읽어 죽은 이유 카드, 첫 등장 안내에 쓴다.

## 셰이더(pack_fx, make_fx.py 패치에 게이브 함수 추가)
- item.vsh: 좀비런 zr_kick, zr_fx 신호와 겹치지 않는 비트 무늬(예: 틴트 R>>4 == 14 + 검사 니블)를 쓴다. 판정 뒤 색은 흰색으로 되돌린다(틴트가 그림을 물들이지 않게).
- 프레임 접기: 자세 k 면은 지금 프레임 = floor((GameTime*24000 + phase) / ticksPerFrame) mod N 일 때만 보이고, 아니면 네 꼭짓점을 한 점(화면 밖)으로 보내 숨김. 주기는 24000 의 약수 틱.
- 가까운 얼굴: 정점의 카메라 거리(Position 은 카메라 기준 세계 축) 3블록 안이면 near 면만, 밖이면 far 면만. 경계에서 깜빡이지 않게 2.8~3.2 사이는 프레임 하나로 정함.
- 켜고 끄기: 부위 칸의 보임 비트가 0 이면 숨김.
- 팔레트(PAL_* 비트)와 맞은 번쩍임(hurtUntil)은 fsh 에서(varying location 8 이상, vsh 와 fsh 가 같은 location). 팔레트는 얼굴 텍스처 색 범위로 고른다(적갈색 눈 줄 → 흰자, 홍조 → 짙은 빨강이나 금빛, 점 입 → 지움 등).
- 셰이더를 고치면 `python ~/.claude/skills/minecraft-shader/scripts/check_shaders.py pack_src --mc 26.3` 0 오류, 그리고 인게임으로 실제 펄럭임이 보이는지 확인.

## Look.java(팩 담당이 쓴다)
- `Look.load(byte[] zip)`: 팩 zip 의 gabe_looks.json 을 읽어 모델별 틴트 역할표를 갖는다(PackServer.reload 가 부르게 요청할 것).
- `Look.colors(model, LookState, worldTime)`: 역할표 순서대로 색 목록. 셰이더와 kit.py 의 비트 배치와 정확히 같아야 한다. 단위 시험(파이썬 kit 의 부호기와 자바 부호기가 같은 입력에 같은 색)을 둘 것.

## 소리
- 종 팩 스크립트가 `sounds()` 로 sounds.json 항목을 돌려준다: 바닐라 소리 파일을 가리키는 것(`{"name": "mob/phantom/flap1", "pitch": 0.6}` 처럼, 이벤트는 gave:gabe.g01.flap), 또는 numpy 로 합성한 mono ogg(권리 깨끗). 자막 키 `subtitles.gave.gabe.g01.flap` 와 한국어 자막. 위협 예고음은 attenuation_distance 를 넓게. 웃음, 킥킥은 떼 종과 극히 일부만.
- build_pack.py 가 props 층, pack_src, gabe 층의 sounds.json 과 lang 을 합쳐 쓴다(덮어쓰지 말고 합치기).
