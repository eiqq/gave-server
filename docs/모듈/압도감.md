사용자(2026-11-12): "거대한 절망감이라든지 압도감이 느껴지면 좋겠어", "게이브 수가 많아야 해". 2026-11-11: "정말 온 사방에서 다 몰려와서 절망적인 감정을 주면 좋겠어, 물론 게임성 밸런스 고려".

## 2. 시야 규칙(싸움을 가리지 않게)

- 디스플레이도 안개를 탄다(26.3 core/item 의 apply_fog). 안개 끝보다 먼 것은 안개 색 한 덩어리라 안 보인다. 그래서 '안개 너머 떼'는 안개 끝 안쪽, 그 자리 색이 화면에 10~34% 남는 거리에 세운다(`C_FAR`, `C_NEAR`). 기본 안개(시작 4, 끝 64)에서 세기 0 이면 58블록, 세기 1 이면 44~50블록(무게에 따라), 큰 물결 순간 40블록. 먼 줄(큰 카드)은 보임 절반이라 더 뒤.
- 해 지는 쪽(세계 시각 13000, 서쪽 좌우 50도)은 하늘이 붉어 안개 색과 카드 색이 모두 밝다. 그쪽 카드는 밝기 3 으로 어둡게 해 붉은 하늘에 검은 그림자 벽으로 서고, 그 밖(어두운 흙빛 하늘)은 밝기 11 로 흐린 얼굴이 드러나게 한다(밝기 3 이면 어두운 쪽에서 거의 안 보였다). 밤 사건(세계 시각 17000 넘음)에는 모두 11.
- 서 있는 모든 사람에게서 `GAP_MIN` 40블록 밖(사람이 사람의 끝 R 48 까지 나가 있으면 그 쪽 카드는 더 밀려남). 대부분의 싸움은 30블록 안이라 실제 게이브를 가리지 않는다. 카드는 안개에 66~90% 묻혀 흐리고 다가오지 않아 30블록 앞의 실제 게이브(밝기 10, 또렷함)와 섞이지 않는다(8절 사진).
- 안개가 짙어 40블록 밖에서는 10%도 안 남으면(안개 3, 4, 5 단계: 끝 38, 26, 14) 카드는 모두 땅으로 꺼지고 소리만 남는다. 실서버에서 '안개 4, 5 단계에 하나도 안 보인다'는 불만이 있었으니 그때 시야를 더 가리지 않는다.
- 맑음(안개 1, 끝 160)에는 가운데에서 116블록(가장 먼 자리)에 그대로 서 있다(안개가 걷혀 지평선 끝까지 떼가 보임).
- 하늘을 메우는 얼굴은 올려다봐야(가운데에서 앙각 40~60도) 보이는 자리라 지평선 쪽 시야를 덮지 않는다. 거대한 그림자도 머리 위를 지난다.

## 3. 감독과 어긋나지 않게

- 카드마다 무게: 가운데에서 본 각도 칸(10도, 36칸)마다 흙먼지 속(가운데에서 40블록 밖) 실제 게이브 수(떼 한 무리 4)를 세어 부드럽게 0..1(이웃 칸 번짐, 10틱마다 20%씩 따라감) + 쏠림 쪽(좌우 50도) 덤. 무게가 큰 쪽 카드부터 보이고 더 가깝다. 감독이 등 뒤 편향으로 낸 무리, 쏠림 덤이 그대로 짙어진다.
- 세기(0..1): 웨이브 0.12 → 10웨이브 0.42 → 20웨이브 0.58 → 40웨이브 0.68(0.12 + 0.6(1 - e^-(w-1)/14)), 몰아치기 +0.14, 마지막 몰아치기 +0.3, 잦아듦 -0.06, 남은 대기열이 동시 수 목표의 4배면 +0.1. 오를 때는 빨리(10틱에 30%), 내릴 때는 천천히(6%). 쉬는 시간, 준비는 0.
- 물결은 감독 `surging()`, `finalSurge()` 가 켜지는 순간: 웨이브 첫 몰아치기는 8웨이브부터 크게, 마지막 몰아치기는 3웨이브부터 크게, 중간 몰아치기는 15웨이브부터 크게(큰 물결 사이 45초). 그 밖은 작은 물결(모든 물결 사이 15초). 마지막 몰아치기가 앞 물결과 15초 안에 오면 버리지 않고 미뤘다가 간격이 차면 낸다(마지막 몰아치기가 이어지는 동안만). 하늘을 메우는 얼굴은 마지막 몰아치기가 시작되는 순간 바로. 웨이브 시작 80틱 안의 `finalSurge()` 는 보지 않는다(감독이 앞 웨이브 값을 첫 내보내기 전까지 들고 있음, 9절 요청).
- 보스가 실제로 나오는 웨이브(`director.bossWave()` 이고 `director.boss` 고리가 있음): 지평선 카드 0, 큰 물결, 거대한 그림자, 하늘 얼굴, 먼 포효 없음(보스 담당 요청, `docs/모듈/보스.md` 19절). 보스는 아래 도구를 쓸 수 있다.
- 소리 없는 웨이브(`director.silent()`): 소리는 모두 끊고 카드 날갯짓을 얼린다(그림자는 그대로 서서 지켜봄).

## 4. 다른 모듈이 쓰는 도구(`game.horizon`)

- `shake(도, 틱)`: 서 있는 사람 모두 아주 약한 화면 흔들림(사인 둘을 겹친 떨림, 처음과 끝 0, 보낸 몫을 되돌려 시선이 제자리로). 이미 더 센 흔들림 중이면 무시. `Guns.kick` 상대 회전 패킷.
- `dusk(시각, 틱)`: 판에 든 사람의 하늘을 상대 시각으로 늦춰 어둡게(사람마다 `setPlayerTime(add, true)`, 끝나면 되돌림). 감독의 밤 사건과 같이 움직인다. 큰 물결에는 기본으로 끔(`Tune.DUSK` 0, 8절 사진 참고).
- `status()`, `displays()`(이 연출의 디스플레이 수).

## 5. 팩

- 모델 `gave:gabe/horizon`(팩 스크립트 `tools/gabe/sp/horizon.py`, 키트, `_Gave` 얼굴 텍스처와 공용 엔드 막대기 텍스처만): 얼굴은 정면 판 하나(먼 얼굴 32), 가오리 날개 막대기 둘은 판 하나씩. Java 가 세로 빌보드(늘 보는 사람 쪽)로 세우므로 앞면만 굽는다. 얼굴은 자세 없이 한 번, 날개만 자세 3(주기 48틱)으로 굽고 마리마다 위상이 달라 따로따로 퍼덕인다(자세 4 는 프레임을 더 먹어 줄임).
- 상태: `""`(40마리: 땅 떼 + 낮게 뜬 것 + 위에 나는 것), `b`(다른 배치 40마리), `c`(큰 것 16마리, 먼 줄). 틴트 칸 4, 면 245/252/91(한도 400), shrink 0.5(엔진이 Look.scale 2 를 곱함), 래그돌 없음. 모델 가운데에서 맨 아래까지 2.17블록(`Horizon.FOOT` 2.2).
- 숨은 카드(땅속)는 꺼진 뒤 view range 0 으로 클라가 아예 그리지 않는다(다시 솟을 때 먼저 되돌림). 보이는 카드만 프레임을 먹는다. 판 시작의 카드 36장은 한 틱에 4장씩 만든다.
- 팩에 이 모델이 없으면(`Look.has` 거짓) G02 떼 덩어리(`gave:gabe/g02` 상태 `lod`)를 3배로 대신 쓴다. 그것도 없으면 그림 없이 소리만.
- 소리는 aud12 의 `sfx.*` 사건(`tools/make_director_sounds.py`, `pack_src`): `sfx.quake`(땅울림, 반경 128), `sfx.horde_cry`(떼의 함성, 128), `sfx.roar_far`(멀리서 울리는 포효, 160), `sfx.colossus`(거대한 것이 지나감, 160). 팩에 없으면 바닐라 대체 소리(워든 솟아남, 좀비 주민, 약탈자 포효, 엔더 드래곤 으르렁)를 낮춰 울린다. 거대한 그림자의 날갯짓은 바닐라 엔더 드래곤 날갯짓을 낮춰.

## 7. 시험 훅(`/gave 시험 압도 x ...`)

`압도 x`(상태 한 줄: 세기, 안개 시작..끝, 보이는 카드, 평균 반지름, 물결 수, 포효 수, 거인 자리, 하늘, 디스플레이 수, 이 연출의 서버 틱 평균/최대 ms), `세기 <0..1|자동>`, `물결 [큰|작은]`, `거인 [진행 방향 도] [옆 블록]`(0 = 서에서 동으로, 가운데 위를 지남), `하늘 [틱]`(그 틱 동안 내려와 있음), `흔들 [도] [틱]`, `해질녘 [시각] [틱]`, `카드`(보이는 카드의 각도:반지름/무게), `거인고정 [앞 거리] [바닥 위 높이]`(멈춘 거대한 그림자), `대신 [on|off]`(G02 덩어리 대신 모델로 다시 세움), `값 [이름 [값]]`, `끔`, `켬`.
시험 팩(공용 팩에 `gave:gabe/horizon` 이 아직 없을 때, 9절 요청 전): `python -X utf8 build/ovw12/make_horizon.py`(굽기, 조각 build/ovw12/frag) → `GV_PACK_OUT=build/ovw12/base-pack.zip python -X utf8 tools/build_pack.py` → `python -X utf8 build/ovw12/make_horizon.py --pack build/ovw12/base-pack.zip build/ovw12/Gave-pack.zip`(gabe_looks.json, sounds.json, lang 은 키를 합침) → `ingame.py --name ovw12 ... --keep-pack`.
대본: `tools/scenarios/ovw12_look.json`(가운데에서 사방, 밝기, 물결, 거인, 하늘 사진), `ovw12_look2.json`(멈춘 거인, 밝기 8 사방, 물결 전후, 하늘, 해질녘, 움직이는 거인, 판 끝), `ovw12_perf.json`(방향별 밝기 사진, 몹 300 + 연출 켬/끔 패킷, 몹시간, 대신 모델), `ovw12_fps.json`(몹 300 + 켬/끔 fps 세 장씩, F3 은 `build/ovw12/f3_wait.py` 를 먼저 백그라운드로: 내 차례가 오면 F3 도우미를 띄움), fps 숫자 모음 `build/ovw12/fps_sheet.py`), `ovw12_natural.json`(웨이브 20 건너뛰어 90초 상태), `ovw12_natural2.json`(웨이브 12, 10초마다 상태).

## 8. 게임 안 확인(2026-11-12, 시험 클라 1280x720, 혼자, 기본 안개 0)

- 사방 사진(`ovw12_look`, `ovw12_perf`, 가운데에서 동서남북): 세기 0.8~1 에서 지평선을 한 바퀴 두른 떼. 서쪽(해 지는 쪽)은 붉은 하늘에 날개 펼친 검은 그림자 벽, 동, 북쪽 어두운 하늘에는 흙먼지 속 흐린 얼굴 떼의 띠. 30블록 앞의 실제 G01 은 더 밝고 또렷해 그림자와 섞이지 않는다. 증거 `build/evidence/ovw12/w1_west_sunset_wall.jpg`, `w2_north_two_looks.jpg`, `w2_east_faces_band.jpg`.
- 밝기: 3 이면 어두운 하늘 쪽에서 거의 안 보이고 8~11 이면 얼굴 떼로 읽힌다(그래서 방향별 밝기). 세기 0.1 은 거의 안 보여 `C_FAR` 를 0.07 → 0.1 로.

## 9. 요청(남의 파일)

- `tools/make_gabe.py`(aud12): 종 번호가 아닌 팩 스크립트 `tools/gabe/sp/horizon.py` 도 굽고 층에 넣기. 지금은 `scripts()` 와 `assemble()` 이 `^g\d\d$` 만 본다. 키 `horizon`, 도감 정보는 `{}`. 그 전까지 공용 팩에는 `gave:gabe/horizon` 이 없고, Java 는 G02 떼 덩어리를 3배로 대신 쓴다. 시험 팩은 `build/ovw12/make_horizon.py --pack` 으로 내 폴더에서만 합친다.
- `tools/gabe/kit.py`(aud12, 선택): `Kit.finish` 가 종이 아닌 키에도 hurt, die 기본 소리 사건(`gabe.horizon.hurt`, `gabe.horizon.die`, 바닐라 슬라임 가리킴)을 넣는다. 해는 없지만 빼면 깔끔.
- `kr.gave.game.Director`(bal12): `beginWave` 에서 `finalOn = false`. 지금은 새 웨이브 첫 내보내기(20~70틱) 전까지 `finalSurge()` 가 앞 웨이브 값(참)을 돌려준다. Horizon 은 웨이브 시작 80틱 안의 값을 무시해 피했지만 HUD, 음악이 읽으면 같은 문제.
- `kr.gave.world.Fog`(맵 담당): 안개 시작 거리(데이터팩 타임라인의 `fog_start_distance`)를 `Fog.START` 로. Horizon 은 지금 같은 숫자를 `FOG_START` 로 따로 들고 있다(데이터팩을 고치면 둘 다).
- 안개 4, 5 단계(끝 26, 14)가 실서버에서 '하나도 안 보인다'는 불만: 숫자는 감독, 맵 담당 일. Horizon 은 그때 카드를 모두 숨긴다.
- `plugin/src/main/resources/config.yml`(뼈대): 설명 한 줄과 `horizon: enabled: true` 를 넣어 두면 운영자가 찾기 쉽다(키가 없어도 켬).
- `docs/구조.md`(뼈대): 1절 `kr.gave.game` 줄에 `Horizon`(압도감 연출), 2절 Game.tick 차례 끝에 `→ horizon`(모든 상태, music 뒤). `docs/모듈/API.md`: 9절 근처에 `game.horizon.shake(도, 틱)`, `dusk(시각, 틱)`, 12.2절 시험 훅 표에 `압도`(Game.test 차례 맨 끝, crates 뒤).
- 실서버에 낼 때(운영): 공용 팩에 `gave:gabe/horizon` 이 들어간 뒤(위 make_gabe 요청) 팩과 jar 를 같이 낸다. 그 전에 jar 만 내면 지평선 떼가 G02 덩어리로 나온다.
