# HUD(kr.gave.game.Hud, tools/make_hud.py 표, pack_hud)

좀비런 방식 그대로(사람마다 보스바 하나의 제목에 글리프, core/text 셰이더가 신호 색 글리프를 화면 칸으로 옮김). 표와 합성기를 게이브용으로 새로 짠다. 원칙: 글 벽 금지, 배치와 강조로 뜻을 전한다(보조 라벨, 설명 문장 넣지 않기). 숫자는 기존 숫자 글꼴, 한국어는 미리 그린 글귀 글리프(Galmuri11).

## 칸(대략, 427x240 과 480x270 GUI 에서 겹치지 않게 잡을 것)
- 맨 위 가운데: 웨이브 번호(크게), 그 아래 남은 게이브 막대(남은 / 총량, 줄어듦). 쉬는 시간에는 남은 초 막대(줄어듦, timed). 준비 단계도 같은 자리. 판 끝은 도달 웨이브. 판 끝 알림 '모두 쓰러졌다'(game_over)는 전멸 연출(director.endTicks(), 200틱)이 끝난 뒤에 뜬다.
- 웨이브 알림 줄(맨 위 가운데 아래): 웨이브 시작 '웨이브 n', 방향 알림(방향 글리프 화살표 + 글귀), 환경 사건(재난문자 꼴 띠: 짙기 1~5 칸 막대와 글귀), 변이 겹치기 이름, 이마 글자 종 실루엣. Hud.notice(key, ticks).
- 오른쪽 위: 재화(동전 그림 + 숫자), 얻은 순간 +n 이 잠깐.
- 오른쪽 아래: 지금 총 실루엣(등급 색 테두리 또는 밑줄), 강화 단계 +n, 탄창 큰 숫자(4분의 1 이하 빨강, 0 깜빡임), 예비 작은 숫자, 재장전 막대, 소모품 칸 아이콘과 개수.
- 왼쪽 아래: 체력 막대(25% 아래 깜빡이는 빨강), 숫자 작게. 받는 피해 순간 막대가 흰색으로 잠깐 깎이는 표시.
- 왼쪽 위: 동료 목록 최대 8줄(쓰러진 사람 먼저 빨강 깜빡임 + 출혈 막대, 갇힌 사람 보라, 죽은 사람 흐림 + 줄, 서 있는 사람, 나는 금색). 30명 판은 넘치면 '서 있음 n/30' 한 줄로 접는다. 줄은 상태가 바뀔 때만 다시 보냄.
- 가운데: 적중 표시(맞힘 흰색, 처치 빨강), 쓰러지면 출혈 고리(월드 바닥에도 늘 보이는 빨간 고리가 남은 출혈만큼 호로 줄어듦, 일으키는 중이면 초록: Players.RING_KIND, ShotFx.downRing), 일으키는 중이면 초록 고리(일으키는 사람과 쓰러진 사람 둘 다), 붙잡히면 탈출 연타 고리.
- 죽은 이유 카드(쓰러진 순간, 가운데 아래): 그 종 아이콘(build/gabe/icons/&lt;종&gt;.png), 종 이름 글귀(name_gxx), 원인 글귀(cause_gxx, 종 담당이 data/phrases/Gxx.json 에 둠). 원인 글귀가 없으면 이름만.
- 처음 보는 종 안내: 그 판에 그 종이 처음 나오면 화면 구석에 아이콘 + 이름이 그 종을 처음 잡을 때까지 남음.
- 화면 덮개(cover): 덮개 키별 전체 화면 그림(240 픽셀 넘는 글리프 금지, 조각으로 나눠 이음). 종 담당이 그림을 tools/gabe/sp/gxx.py 에서 만들어 build/gabe/covers/&lt;키&gt;.png 로 두면 make_hud 가 덮개 글리프로 굽는다(덮개 키 목록은 make_gabe 가 build/gabe/covers.json 에). 덮개는 한 번에 하나.
- 방향 글리프: 붙잡히거나 쓰러진 동료 쪽(화면 가장자리 작은 화살표), 웨이브 방향 알림.
- 상점 안: 상점 표시(카운터 쪽 아이콘). 상점 화면 자체는 상자 메뉴라 HUD 가 아님.
- 증강 고르기는 상자 화면(총상점.md)이라 HUD 는 '증강 n장 대기' 표시 정도.

## 합성기(Hud.java)
- 매 틱 사람마다 HudScreen 에 칸을 채우고 flush(바뀐 칸이 있을 때만 보냄). 남의 줄에 매 틱 바뀌는 값(동료 체력 숫자 등)을 넣지 않는다.
- 다른 모듈이 부르는 메서드(뼈대 Hud 에 있음): notice, hit, money, cause, cover, uncover, forget, clear, test. 더 필요한 것: pointers(동료 방향), firstSeen(종), wave/break 표시는 Game, Director 를 읽어 스스로.
- 게이브 아이콘이 아직 없는 종은 빈칸(얼굴 기본 아이콘)으로.
- 시험 훅 `허드 <이름>`(보낸 횟수와 칸 설명), `알림 <이름|all> <키> [틱] [짙기]`, `카드 <이름> <종|-> [원인키]`, `허드덮기 <이름> <키|off> [틱]`(`덮기` 는 Players 훅), `표시`, `게이지`, `적중`, `처음 x <종>`, `처음잡음 x <종>`, `가짜남은 x [틱]`, `허드방향 x <틱> <yaw...>`(`방향` 은 감독 훅), `가리키기`, `깜빡`, `허드동료 x <수>`, `도움말 <이름> <키>`, `알림줄 <이름>`(지금 띠와 줄 선 키), `웨이브알림 x <웨이브> <키[:짙기]...>`, `이름숨김 x <on|off>`. 전체 꼴은 `docs/모듈/API.md`.

## 생성기(make_hud.py)
- SLOTS, PALETTE, 그림, 모양 표를 게이브용으로. 글귀: data/phrases/*.json + 종 이름(data/bestiary.json). 아이콘: build/gabe/icons. 덮개: build/gabe/covers.json. 총 실루엣: 기존 방식(props 층 총 모델).
- 실행 뒤 `compile_wip.py --name hud --promote` 로 HudSpec.java 를 코드에 넣는다. 셰이더 검사 통과 전에는 아무것도 쓰지 않는 기존 안전장치 유지.
- `--mock` 으로 427x240, 480x270 배치 그림을 만들어 직접 보고(Read 로 png 확인) 겹침이 없는지 본다.
