# 종 작성법(G03 .. G55 담당용)

한 종 = 파일 둘. 팩 스크립트 `tools/gabe/sp/gxx.py`(모델, 상태, 텍스처, 소리, 글귀, 아이콘, 덮개)와 Java `plugin/src/main/java/kr/gave/mob/sp/Gxx.java`(행동). 두 파일은 **상태 이름, 부위 이름, 소리 이름, 글귀 키**로만 이어진다. 본보기는 `tools/gabe/sp/g01.py`(돌격, 지느러미 둘), `g02.py`(떼, LOD), Java `G01.java`, `G02.java`.

## 1. 순서

```
python -X utf8 tools/make_gabe.py --only g05 --preview     # 굽기 + build/gabe/preview/g05.png
# 미리보기 그림을 Read 로 직접 본다(아래 6절 배치)
python -X utf8 tools/make_hud.py && python -X utf8 tools/compile_wip.py --name hud --promote   # 글귀, 아이콘을 바꿨을 때만(HUD 담당 도구)
python -X utf8 tools/compile_wip.py --name g05             # Java(새 파일은 build/wip/g05/... 에 먼저)
python -X utf8 tools/ingame.py --name g05 --scenario tools/scenarios/<대본>.json > build/g05/ingame.out 2>&1
```

- `make_gabe.py --only` 는 그 종 조각(`build/gabe/sp/g05/`)만 새로 굽고 층(`build/gabe/pack_layer/`)을 다시 모은다. 다른 종 조각은 그대로. 여러 사람이 같이 돌려도 잠금(`build/locks/make_gabe.lock`)으로 줄을 선다. 한 종이 실패해도 나머지로 층을 만들고 종료 코드 1.
- `ingame.py` 는 실행마다 그때의 `build/gabe/pack_layer` 로 팩을 묶는다(`--keep-pack` 이 아니면). 굽고 나서 돌린다.
- 셰이더는 고치지 않는다(팩 담당 `pack_fx/gabe.glsl`). 필요한 기능은 요청으로.

## 2. 좌표와 약속

- 단위 블록, 모델 가운데(엔진 `Gabe.pos` = 디스플레이 자리 = 맞는 구 중심)가 (0, 0, 0). **+Y 위, +Z 앞(얼굴 정면, 엔진이 이 쪽을 `yaw` 방향으로 돌림), +X 는 게이브 자신의 왼쪽**(마주 본 사람에게는 오른쪽).
- 부위 이름의 `_l`, `_r` 은 게이브 자신 기준: `_l` = +X. Java 에서 몸 왼쪽 벡터: 보는 방향 `f = (-sin yaw, 0, cos yaw)` 일 때 왼쪽 `L = (f.z, 0, -f.x)`.
- 요소 상자(회전 전)는 모델 틀 -16..32 px 안이어야 한다 = 가운데에서 대략 ±1.5 블록. 사슬(막대기, 띠)은 이음점만 틀 안이면 끝은 밖으로 나가도 된다(키트가 상자를 이음점에서 세워 회전으로 눕힘). 더 큰 종은 `k.model(shrink=0.5)` 로 줄여 굽고, 엔진 `Body` 가 `Look.scale(model)` 배를 곱한다(요청해 둠).
- 이름(모델, 상태, 부위, 소리, 텍스처, 덮개)은 소문자, 숫자, `_` 만. 기본 상태는 `""`.
- 가운뎃점 문자 금지(자막, 글귀 모두. 키트가 막음). 실제 사람 얼굴은 팩 텍스처(`_Gave` 스킨)로만.

## 3. 팩 스크립트 꼴

```python
from gabe import audio, kit

def build(k: kit.Kit):
    m = k.model(poses=8, period=20)            # 아이템 정의 gave:gabe/g05
    for name, cycles in (("", 1), ("swell", 2)):  # swell 은 같은 20틱에 두 번 침(두 배 빠르게)
        s = m.state(name)                      # 상태 = custom_model_data strings[0]
        h = s.head(size=0.7, face="smile")
        for side in (1, -1):                   # 원형 DNA: 펄럭이는 엔드 막대기 둘
            s.rod(h.point(side * 0.9, -0.4, -0.6), (side, 0.2, -0.5), length=0.9,
                  wave=kit.Wave(amp=(18, 16, 14), lag=45, cycles=cycles))

def sounds(k: kit.Kit):
    k.sound("pop", "퍽", vanilla=[("mob/slime/big2", 0.7)], synth=lambda i: audio.squish(seed=50 + i), attenuation=24)  # 옛 꼴
    k.sample("burst", "tag:wet+slime", "터짐", pitch=0.8, attenuation=24)  # 새 종은 받은 소리로(4절 '받은 소리')

def phrases():
    return {"cause_g05": "혹이 터졌다"}
```

`build` 는 꼭 있어야 하고 `sounds`, `phrases` 는 없어도 된다. `phrases()` 가 있으면 `data/phrases/G05.json` 을 make_gabe 가 덮어쓴다(그 파일을 손으로 고치지 말 것). 글귀 키는 종 번호를 붙여(`cause_g05`, `notice_g05_x`) 다른 종과 겹치지 않게(겹치면 make_hud 가 멈춤).

## 4. 키트 API(tools/gabe/kit.py)

| `k.texture(name, img, classes=False)` | 종 전용 텍스처(PIL 또는 RGBA 배열) → id `gave:item/gabe/<종>/<name>`. 알파는 0 또는 255 만(반투명 금지). 파랑 아래 3비트(화소 부류)를 0(살)으로 지운다: 아무 그림이나 팔레트에 얼룩지지 않게. 부류를 일부러 새긴 그림(`faces.Canvas.rgba()`)만 `classes=True` |

| `k.face_tex(face, near=False)` | 얼굴 텍스처 id(먼 32 또는 가까운 128) |

| `k.sample(name, src, subtitle=None, *, pitch=1, volume=1, attenuation=16, n=3, level=-14)` | **새 소리는 이것으로**(2026-11-12): 내려받은 CC0, CC BY 효과음(`data/sfx_lib.json`, 921개)으로 같은 사건을 만든다. 아래 '받은 소리' |
| (자동) `hurt`, `die` | 엔진(Mobs)이 모든 종에 울리는 사건 `gabe.<종>.hurt`(반경 16), `gabe.<종>.die`(24). 종이 같은 이름으로 `k.sound` 를 안 부르면 키트가 기본값(슬라임 소리 피치 바꿈, 자막 "게이브 움찔", "게이브 철퍽")을 넣는다. 엔진 공용 `gabe.bite`, `gabe.split` 은 `tools/gabe/common.py` |
| (자동) `idle`, `gait` 또는 `gait_<재질>`, `flesh` | 보탠 크리처 소리(2026-11-14): 키트가 `data/gabe_voice.json` 의 그 종 줄대로 공용 사건을 가리키는 별칭을 더한다(`{"name": "gave:gabe.cry_mid", "type": "event", "pitch": 몸집 높이}`, 자막은 공용 사건 것). `idle` = 울음 사건이 없는 종만(`cry_small`, `mid`, `big`, `ground`), `gait` = 이동 사건이 없는 종만(`move_flap`, 또는 재질 넷 `gait_dry`, `mud`, `ash`, `pad` → `move_tick`, `pat`, `thud`, `drag`), `flesh` = 모든 종(죽을 때 얹는 살덩이 층 `flesh_small`, `mid`, `big`). 엔진(`kr.gave.mob.Ears`)이 듣는 사람마다 예산을 걸고 부르므로 종 Java 는 할 일이 없다. 종이 같은 이름으로 `k.sound` 를 부르면 그것이 이긴다. 새 종은 표에 한 줄 더하고(흉내, 숨는 종은 `cry`, `move` 를 null), 표를 고치면 종 전체를 다시 굽는다. 공용 사건은 `tools/gabe/flesh.py` NEAR(`docs/소리출처.md` '크리처 보강 소리') |

| `k.icon(img=None, *, model=None, state=None, view="front")` | HUD 아이콘 64x64. 안 부르면 첫 모델 기본 상태 정면 그림이 저절로 → `build/gabe/icons/<종>.png` |

### Model
- `m.state(name="", *, poses=None, period=None)` → State. 상태마다 모델 파일 하나(`models/item/gabe/g05_swell.json`).
- `m.default = "a"`: `""` 상태를 만들지 않는 종(떼 G02)은 기본(빈 strings 일 때) 상태를 정한다.
- `m.mut2 = dict(root=(x, y, z) 또는 lambda side: (...), dir=(x, y, z), length=, segs=2, thick=, wave=, toward=, poses=4)` 로 변이 2 막대기 자리를 바꾸거나 `False`. 기본은 두 마디, 자세 4(개체 대부분은 숨긴 채 살지만 면은 늘 실림).

### State(모델 하나의 기하)
| 부름 | 뜻 |
|---|---|
| `s.head(size=0.8, depth=None, at=(0,0,0), face="smile", *, height=None, near=True, sides="skin", open=None, torn=None, rot=None, show=())` → Head | 얼굴 상자: 앞(+Z) 먼 얼굴 32, 3블록 안 가까운 얼굴 128(`near=False` 면 없음), 옆, 뒤, 위, 아래는 스킨 머리. 실눈 뜸, 입 찢어짐 오버레이 저절로. `rot=(x, y, z)` 도 |
| `h.point(u, v, w)` | 얼굴 상자 위 점(블록): u 가로 -1(오른쪽 -X)..1(왼쪽 +X), v -1 아래..1 위, w -1 뒤통수..1 앞면 |
| `s.rod(root, dir, length=1.2, segs=3, thick=0.11, wave=None, toward=(0,1,0), base=True, poses=None, rag=None)` → Chain | 엔드 막대기 사슬. `toward` = 물결 각도가 + 일 때 휘는 쪽(기본 위, 꼬리를 좌우로 흔들려면 (1,0,0)). `wave=None` 이면 자세 없이 가만히. `base` = 뿌리 받침 하나(자세 없음, 첫 마디가 그 안에서 돎). `poses` = 이 부위만 자세 수(기본 상태 자세 수, 작은 부위는 4). 면 = 자세 x (마디 x 4 + 1) + 받침 6. `rag` = 죽은 뒤 이 막대기가 흐물거리는가(5.1절) |
| `s.band(root, dir, length, width, segs=3, thick=0.03, wave=None, toward=(0,1,0), tex="flesh", face=True, poses=None)` → Chain | 납작한 띠(살 띠, 젖은 천 가장자리, 혀, 보자기). 폭은 휘는 축 쪽. 1/16 블록보다 얇으면 넓은 두 면만(면 = 자세 x 마디 x 2) |
| `s.chain(a, b, links=6, sag=0.25, size=0.09, tex="chain", swing=None, poses=None)` | a 에서 b 로 늘어진 쇠사슬(고리마다 두 면), `swing=Wave` 면 흔들림 |
| `s.membrane(chainA, chainB, tex="web")` | 두 사슬 사이 막(거미줄, 물갈퀴). 자세마다 따라 움직임(두 사슬의 자세 수가 같아야 함) |
| `s.teeth(center, radius, count=10, axis=(0,0,1), length=0.08, size=0.04, tex="bone", inward=0.3)` | 뼈 이빨 고리 |
| `s.lump(count=16, radius=(1,0.45,1), size=0.3, faces_list=[...], wobble=0.0, seed=1, poses=None)` | 멀리서 보는 떼 덩어리(LOD). 출렁임 자세 기본 min(4, 상태 자세 수), 면 = count x 6 x 자세 |
| `s.box(frm, to, tex, *, uv=None, faces=None, rot=None, origin=None, dist="any", face=False, show=())` | 아무 상자(블록 좌표). `tex` id 하나 또는 `{면: id}`(공용 부품 이름도 됨), `uv` 0..16 |
| `s.quad(center, (w, h), facing="south", tex, ...)` | 두께 0 판 하나 |
| `with s.when("on:cut_l", "mut<2"):` | 이 안의 요소는 조건이 모두 맞을 때만 보임 |
| `for f in s.frames(poses=None): with f: ...` | 손으로 짜는 자세 애니메이션: `f.k`(0..N-1), `f.t`(0..1) 로 모양을 정해 요소를 만들면 그 자세에서만 보임(N = poses, 기본 상태 자세 수) |

조건: `open`, `!open`, `mut>=N`, `mut<N`, `mut==N`, `on:<부위>`, `!on:<부위>`. 부위 이름은 조건에 쓰는 순간 생긴다(Java 는 `body.look.on.add("cut_l")`).

### Wave(펄럭임 물결)
`kit.Wave(amp=20, lag=40, bias=0, phase=0, shape="sin", cycles=1)`: 마디 i, 자세 시각 t(0..1) 의 각도 = `bias_i + amp_i * f(2π*cycles*t - i*lag + phase)` 도, 뿌리부터 쌓인다. `cycles=2` 는 상태 주기 한 바퀴에 두 번 쳐서 두 배 빠르게(자세 N 장을 두 바퀴가 나눠 씀). `amp`, `bias` 는 수 하나나 마디마다 목록. `lag` 가 크면 뿌리에서 끝으로 늦게 퍼지는 파도. `shape`: `sin`, `flap`(빨리 치고 천천히 내림), `twitch`(대부분 가만히, 한 번 움찔). 좌우 막대기를 엇갈리게 하려면 한쪽에 `phase=180`.

### 얼굴(tools/gabe/faces.py)
- 이름 있는 처방(`face="..."`): `smile`(기본 실눈 웃음), `half`(반쯤 뜬 눈), `open`(다 뜬 눈), `bloodshot`(핏발 선 흰자 바늘 동공), `torn`(귀까지 찢어진 입), `tears`(눈물), `blank`(무표정), `gold`(금빛 홍조), `deep`(짙은 홍조), `stitch`(바늘땀 이음선), `half_v`(세로 반쪽, 오른쪽 투명), `flipped`(뒤집힌 얼굴), `teeth_ring`(이빨 고리 입), `honeycomb`(벌집 구멍 입), `smile_a`, `smile_c`(실눈 기울기 다름).
- 섞어 새로: `faces.Face(eyes="open", mouth="teeth_ring", blush="deep", extras=("tears", "stitch"), cut=None, flip=False, tilt=0, tufts=True)`. `eyes`: squint, half, open, bloodshot, none / `mouth`: dot, torn, teeth_ring, honeycomb, none / `blush`: pink, gold, deep, none / `extras`: tears, stitch, veins / `cut`: left, right. 가까운 얼굴(128)과 오버레이는 같은 처방에서 저절로.
- 완전히 새 그림이 필요하면 `faces.draw(face)` 로 Canvas 를 받아 `put`, `stamp`(아스키 조각, 글자 표 `faces.PAL`)로 고친 뒤 `k.texture(...)` 로 싣는다. 이때 화소 부류(파랑 아래 3비트)를 지켜야 팔레트가 먹는다: 0 살 1 눈 줄, 홍채 2 홍조 3 입 4 흰자 5 반짝임 6 머리 덩어리 7 이. `Canvas.rgba()` 가 부류를 굳혀 준다.

### audio(합성 소리, tools/gabe/audio.py)
조립: `tone, noise, env, lowpass, highpass, bandpass, mix, cat, at, gain, fade, normalize`. 본보기: `giggle`(킥킥 파도, 떼 종만), `wet_flap`(젖은 천 퍼덕), `squish`(찌그러짐), `chitter`(작은 떼 지저귐), `thump`(쿵). 모두 mono 44.1kHz float 배열, 같은 씨앗이면 같은 소리. 2026-11-11 사용자 정정("합성하지 말고 어디서 다운해 와") 뒤로 새 종과 보스의 소리는 합성하지 않고 아래 받은 소리로 만든다(이미 구운 종의 합성 소리는 그대로).

### 받은 소리(k.sample, 2026-11-12)
내려받은 CC0, CC BY 효과음 921개(원본 `ref/sfx/<묶음>/`, 출처와 라이선스 `docs/소리출처.md`, 목록 `data/sfx_lib.json`)로 소리 사건을 만든다. 팩이 공개 배포라 다른 곳에서 소리를 따로 받아 오지 말고 이 목록에서 고른다(더 필요하면 소리 담당에게 요청).

```python
def sounds(k: kit.Kit):
    k.sample("hit", "kenney_impact/impactpunch_heavy_000", pitch=1.2)                 # 아이디 하나(자막은 태그에서: '쿵')
    k.sample("roar", "tag:roar", "포효", attenuation=48, pitch=0.7)                     # 태그로 찾아 3개(n=3)를 변형으로
    k.sample("snarl", "oga_snarls/monster_snarls_0#1", "으르렁", pitch=0.8)            # 긴 녹음의 덩어리 #1
    k.sample("moan", ["oga_zombies/zombie_4", {"id": "oga_moans/darsycho_zombie_moans_0", "start": 3.6, "end": 6.2, "pitch": 0.7}],
             "신음", attenuation=24)                                                     # 여럿, 구간과 높이를 따로
    k.sound("bump", "철퍽", vanilla=[("mob/slime/big2", 0.7)], sample=["tag:wet+slime"])  # 바닐라와 섞기
```

- `src` 꼴: 아이디 `'<묶음>/<이름>'`, 긴 녹음의 소리 덩어리 `'<아이디>#<번호>'`(목록의 `parts`), 태그 `'tag:roar'`(여럿은 `'tag:roar+far'`, 빼기 `'tag:roar-boss'`, n 개를 아이디 차례에서 사건 이름으로 정한 자리부터 고른 간격으로: 같은 입력이면 늘 같은 것, 6초 넘는 녹음은 그 덩어리로 바꿔 고름), glob `'oga_zombies/zombie_1*'`, `dict(id=.., pitch=.., volume=.., start=초, end=초, level=dB, max_len=초)`, 또는 그 목록.
- 다듬기(`audio.prepare`): 앞뒤 무음 자름, 가장 큰 0.4초 크기를 `level` dBFS(기본 -14, 피크 -1 아래)로 맞춤, mono(자리 소리), libvorbis q4 → `assets/gave/sounds/gabe/<종>/<name>_s<i>.ogg`. 8초 넘는 것은 `stream`. 높이는 파일을 바꾸지 않고 sounds.json `pitch` 로(낮추면 크고 멀게: 포효 0.5~0.75, 떼 신음 0.7~0.85, 웃음은 높여 1.1~1.25).
- 자막: `subtitle` 을 안 주면 찾은 태그(없으면 첫 소리의 태그)의 한국어(`roar` → 포효, `quake` → 땅울림). 가운뎃점 금지는 그대로.
- 찾아보기: `python -X utf8 tools/gabe/audio.py find tag:roar`(아이디, 길이, 크기, 저음 몫, 태그), `find "oga_snarls/*" parts`(덩어리 시각). 압도감 쪽 태그: `far_roar`, `horde_cry`, `quake`, `colossus`, `boss_roar`, `giant`, `horn`, `thunder`, `wind`, `heartbeat`, `overwhelm`(손으로 고른 압도감 후보). 묶음별 소리는 `docs/소리출처.md`.
- 같은 받은 소리를 여러 종이 써도 된다(파일은 종마다 따로 구워짐). 이미 다듬어 팩에 든 공용 사건(`sfx.roar_far`, `sfx.quake`, `sfx.boss_roar` ...)은 Java 에서 바로 부를 수 있다(`docs/소리출처.md` '바로 쓰는 압도감 사건'): 종 팩에 같은 소리를 또 굽지 않아도 된다.
- CC BY 묶음(`lrsf_horror`)을 쓰면 저작자 표시는 팩 CREDITS [7b] 에 이미 들어간다(묶음 전체를 적음). 쓴 받은 소리는 `k.samples` 에 차례대로 남는다.
- 기존 종은 그대로 굽힌다(키트를 고친 뒤 55종 모두 바이트까지 같음 확인, `build/aud12/bake_compare.py`).

## 5. 겉모습 상태(LookState)와 틴트 칸(자동)

틴트 칸 역할표는 키트가 저절로 만든다(손댈 일 없음). 칸 = (자세 면/보통 면, 거리, 얼굴 여부, 조건, 자세 k, N). 주기는 칸에 들지 않는다: 상태끼리 같은 자세 칸을 나눠 쓰고, 상태 이름을 아는 `Look.colors(model, state, look, wt)` 가 그 상태의 주기를 실어 보낸다(그 상태 모델이 안 쓰는 칸은 기본값으로 두고 끝을 잘라 보냄). 상태 이름을 모르는 `Look.colors(model, look, wt)` 는 칸마다 기본 상태 주기로 싣는다. **상태마다 빠르기를 달리하려면 주기는 그대로 두고 `Wave(cycles=2)`**(같은 주기 안에서 두 번 침, G01 charge)로 하는 것이 안전하다: 어느 `colors` 로 실어도 맞다. `m.state("x", period=10)` 처럼 상태 주기를 따로 주어도 된다: 엔진 `Body.item` 이 2026-11-10 통합부터 상태를 아는 `colors` 를 부른다(떼 마리, 덩어리, 부품도 같은 길). 다만 바닐라 `summon` 으로 겉모습만 보는 대본은 `kit.colors_state` 를 써야 맞다. 모델 하나에 칸이 많을수록 겉모습이 바뀔 때 보내는 데이터가 커지므로 **모델 하나 80칸 이하**(미리보기 요약 줄의 `틴트 칸`, G01 은 40). 칸을 아끼려면: 자세 없는 부위는 `wave=None`, 끊김 그루터기 같은 것은 자세 없이, 조건(`when`) 조합을 늘리지 않기.

**면 수 한도(상태 모델 하나 400, `k.model(budget=)`)**: 프레임 접기는 모든 자세의 면을 모델에 굽고 셰이더가 지금 자세가 아닌 면을 접는다. 접힌 면도 클라가 매 프레임 정점으로 계산해 보내므로 몹 200마리면 200배가 된다. 그래서 숨긴 자세 면, 조건 면(`mut>=2` 막대기, 끊김 그루터기)을 모두 센다. 요약 줄 `면 [...]` 과 `check_layer.py` 가 상태마다 보여 주고, 넘으면 굽기가 실패한다. 줄이는 법: 작은 부위는 `poses=4`, 마디 수 2, 얇은 띠는 1/16 블록보다 얇게(두 면만), 큰 부위는 다른 상태나 부품 디스플레이(`body.attach`)로. G01 은 상태마다 385(지느러미 둘 8자세 220, 젖은 천 48, 변이 2 막대기 84, 그루터기 22, 얼굴 11), 기본 look 에서 보이는 것은 약 50.

| Java `body.look` | 화면 |
|---|---|
| `open = true` | 실눈이 뜨임(모든 얼굴의 open 오버레이). 표적을 찍은 종만(`Gabe.mark`) |
| `mut = 1` | 입 찢어짐(torn 오버레이), `mut = 2` 막대기 둘 더(엔진이 오래 살면 올림) |
| `on.add("부위")` | `on:부위` 조건 요소가 보이고 `!on:부위` 요소가 숨음 |
| `palette` 비트 `Look.PAL_WHITE_EYES 1`, `PAL_PALE 2`, `PAL_DEEP_BLUSH 4`, `PAL_BLANK 8`, `PAL_GOLD 16` | 얼굴 텍스처 색 바꿈(흰 눈, 탈색, 짙은 홍조, 무표정, 금빛 홍조). 자세 면(막대기)에는 안 먹음 |
| `freeze = true` | 펄럭임 멈춤(자세 0), `rate` 펄럭임 빠르기 배율, `phase` 개체 위상(틱) |
| `hurtUntil = worldTime + 3`(엔진 `Body.flash`) | 흰 번쩍임(보통 면만: 얼굴, 살 띠처럼 자세 없는 면. 빛을 되갚아 그늘, 밤에도 하얗게. 자세 면(펄럭이는 막대기, 띠)은 안 번쩍임). 도장이 480틱마다 다시 맞으므로 엔진이 매 틱 `Look.settle(look, worldTime)` 으로 지나간 것을 지우고 다시 싣는다(Body, Part, Swarm 마리). 종 코드가 `hurtUntil` 을 직접 넣어도(G02 처럼) 그 look 이 엔진이 sync 하는 것이면 된다 |
| `palette` 와 공용 부품 | `face=True` 인 자세 없는 띠, 상자도 팔레트를 받지만 공용 부품 텍스처는 화소 부류 0 이라 탈색만 먹는다(흰 눈, 무표정, 홍조 바꾸기는 얼굴 텍스처에만) |

거리: 얼굴 앞면은 먼 면(32)과 가까운 면(128)을 겹쳐 두고 셰이더가 그 면 평면까지 거리 3블록으로 고른다. 새 요소에 `dist="near"`/`"far"` 를 주면 같은 방식.

### 5.1 사체(래그돌, 저절로 구워짐)

죽은 게이브는 래그돌 사체가 된다(엔진 `Ragdoll`, API.md 5.1절). 팩 쪽은 키트가 모델마다 저절로 굽는다. **종 스크립트를 고칠 필요는 없다.**
- 상태마다 몸 상자(기본 겉모습, 자세 0 에서 보이는 요소의 테두리)를 재서 `gabe_looks.json` 의 `rag` 에 적는다. 엔진이 그 상자로 구르고 튕긴다.
- **흐물 막대기**: `s.rod` 에 `wave` 를 준 막대기 가운데 길이 0.3 이상인 것(긴 것부터 4개, 텍스처는 공용 부품 rod, flesh, wetskin, bone). 죽으면 이 막대기들이 몸에서 떨어져 공용 마디 모델(`gave:gabe/common_rod`)로 흐물거린다. 가만히 있는 막대기(`wave=None`), 띠, 사슬, 손으로 짠 자세 요소는 몸에 굳은 채 같이 구른다. 흐물 막대기에 걸친 막(`s.membrane`)은 사체에서 빠진다.
- 흐물 막대기가 있는 상태마다 **사체 상태 `<상태>.c`** 가 하나 더 생긴다(막대기 뺀 몸 + 바닥에 닿는 면 6가지마다 누운 막대기 자세). 엔진이 구르는 동안은 막대기 뺀 몸으로, 멈추면 누운 자세를 켜 디스플레이 하나로 합친다. 면 수 한도나 칸 수 80 을 넘으면 누운 자세가 4, 2, 1, 0 가지로 줄어든다(0 이면 굳을 때 막대기가 오므라들어 사라짐). 상태 이름에 점이 들어가므로 종이 짓는 이름과 겹치지 않는다. 틴트 칸이 조금 늘 수 있다(G01 40 → 47).
- **얼굴 방향**: 사체는 얼굴을 바닥에 깔고 굳지 않는다(엎어지면 굴러 넘어가 뒤로 눕는다). 키트가 상태마다 얼굴이 보는 방향을 굽는다(`rag.front`: 그 상태에서 가장 큰 `s.head()` 의 앞면, `rot` 으로 돌려 붙인 머리도 맞게). `head()` 없이 얼굴을 그린 상태는 엔진이 닻 몸과 떼 마리는 앞(+Z), 부품은 얼굴 없음으로 친다. 다르면 `s.front = (0, 1, 0)` 처럼 적는다(`(0, 0, 0)` = 얼굴 없음: 아무 면으로나 눕는다).
- 사체는 서로 쌓이고(굳은 사체 위에 다음 사체가 올라앉음), 물리 단계에 자리가 없는 죽음은 값싼 단계(디스플레이 하나, 누운 막대기 자세로 날아가 눕기)로 간다. 둘 다 엔진이 알아서 하므로 팩 쪽에서 할 일은 없다. 값싼 단계의 사체는 사체 상태의 누운 자세를 처음부터 쓰므로, 누운 자세가 어색한 종은 물리 단계보다 눈에 띈다.
- 바꾸는 법(선택): `s.rod(..., rag=False)` 그 막대기는 몸에 굳은 채, `rag=True` 가만히 있는 막대기도 흐물거림, `rag=2`(정수) 흐물 마디 수(기본은 길이 0.5 아래 1, 1.5 아래 2, 그 위 3), `k.model(rag=False)` 모델 통째로 끔(얼어붙은 몸이 통째로 구름: 덩어리 LOD 모델, 떼 마리 모델처럼 사슬이 필요 없는 것).
- 확인: 굽기 요약 줄 끝 `사체 [상태 n, 누운 자세 6, 흐물 막대기 n]`, 미리보기 맨 아래 줄(짙은 남색 바탕)의 [얼굴이 하늘을 볼 때 위에서 본 모습, 바로 섰을 때 위에서 본 모습, 막대기 뺀 몸] + 누운 자세 띠.
- Java 쪽 값: `leaveCorpse`(false 면 사체 없음), `ragdoll`(false 면 예전 납작 사체), `ragKick`(충격 배율), `ragRods`(흐물 막대기 수 상한). 터지는 종, 쪼개지는 종은 지금처럼 `die()` 에서 알아서.
- 게임에서 보기: `/gave 시험 몹치기 <이름> PELLET 3 G05 [방향 yaw]`(가까운 개체부터 그 피해로 죽임, 방향을 주면 그쪽으로 날아감), `/gave 시험 래그돌 <이름>`(사체 수, 가장 새 구의 상태), `/gave 시험 래그돌검사 <이름>`(굳은 면별 수, 얼굴이 깔린 수, 더미 높이), 값싼 단계만 보려면 `/gave 시험 래그돌값 <이름> active 0`. 본보기 대본 `tools/scenarios/ragdoll_b.json`, `ragdoll_e.json`(더미, 굴러 넘어가기, 값싼 단계).

줄마다 [정면, 옆(+X 에서), 위(앞이 아래)] 큰 그림 + 자세 띠(정면, 자세 0..N-1 을 둘씩 세로로). 상태마다 한 줄, 모델마다 그다음 줄은 기본 상태의 [실눈 뜸, 변이 1, 변이 2, 가까운 얼굴], 래그돌 사체 상태가 있으면 맨 아래 줄에 사체(5.1절). 빛, 셰이더 없는 그림이라 게임 화면과 같지는 않다. 게임에서 꼭 본다.

## 7. Java 쪽(엔진 API 요약, 자세한 것은 `kr.gave.mob.Gabe`, `Body`, `Swarm`, `Mobs` 의 javadoc)

- 클래스 `kr.gave.mob.sp.Gxx extends Gabe`, 생성자 `(Game, Species)`. 수치는 생성자에서(`radius`, `hover`, `baseSpeed`, `flying`, `ghost`, `noPush`, `noMutate`, `noBite`, 사체 `leaveCorpse`, `ragdoll`, `ragKick`, `ragRods`), 몸은 `build()`(기본 `Body.of(this, "gabe/gxx")`), 행동은 `tick()` 에서 `vel` 과 `yaw` 만 정한다(적분, 벽, 밀어내기, 판 규칙은 엔진).
- 겉모습: `state("charge")`(= 팩 상태 이름), `body.look.on.add("cut_l")`, `body.look.open`, `body.look.palette |= Look.PAL_GOLD`, `body.look.rate = 2`, 바꾼 뒤 엔진이 다음 `move()` 에 다시 싣는다. `body.squash(x, y, z, ticks)`, `body.roll`, `body.offset`, `body.scale(s, ticks)` 는 디스플레이 변환(셰이더와 별개).
- 부품 디스플레이: `body.attach("gabe/g05_sac")` → Part(따로 상태, look, `pose(Matrix4f, ticks)`). 모델은 같은 팩 스크립트에서 `k.model("g05_sac")` 로 굽는다.
- 떼: `Swarm`(`members`, `add(home, "a")`, `Member.state`, `look`, `lodState = "lod"`, `formation`, `flinch`). 본보기 `G02.java`.
- 도우미: `follow`, `seek`, `dash`, `face`, `turnTo`, `nearest`, `acquire`, `mark`(실눈 뜸), `touches`, `hit(p, dmg, "cause_gxx")`(글귀 키), `knock`, `grab`, `sound("pop", Sound.ENTITY_SLIME_SQUISH, 16)`(팩 사건 `gabe.gxx.pop`, 없으면 바닐라 대체음), `child`, `kin`.
- 맞는 구는 `spheres()`(여러 마디 종은 덮어씀), 맞을 때 `damage(Damage)`.
- 시험 훅: `/gave 소환 <종> [수] [거리] [이름]`, `/gave 시험 몹정지 <이름> on|off`, `몹보기`, `몹목록`, `몹죽이기`, `보기 <이름> <종> <틱>`, `예산`.
- 모든 모듈 API(Players, Hud, Director, Shop, Augments, 시험 훅)를 모은 것은 `docs/모듈/API.md`.

### 감독이 놓는 방식과 지킬 것(2026-11-10 감독 담당)
- **대기실 우리 개체**: 감독은 생성자 다음, `spawned()` 앞에 `untargetable`, `noRules`, `noMutate`, `noBite`, `noReward`, `reward = 0` 을 걸고 `Mobs.place` 를 부른다. 그동안 `game.director.cageSpawning()` 이 true 다. 그때 `spawned()` 는 자리를 옮기거나 소리, 붙잡기, 알림처럼 사람 쪽 일을 하지 않는다(옮기면 감독이 우리 안으로 되돌림). 우리 개체인지는 `game.director.inCage(this)`. 우리 개체는 `Mobs.lure` 로만 움직이므로 종 `tick()` 은 불리지 않는다.
- **미리 깔리는 종(Species.Spawn.PLACED)**: 감독이 `placeFor(sp)` 자리에 `Director.placedCap(sp, 접속자)` 만큼만 놓는다(처음 나오는 웨이브는 하나). 처마 종(G21)은 안 쓴 처마, 문틀 종(G47)은 안 쓴 문틀. 사람을 잡거나 쫓는 PLACED 종은 `mark(p)` 로 `target` 을 세워야 그 웨이브가 끝나지 않는다(PLACED 이면서 target 이 null 인 것만 남으면 20초 뒤 웨이브 끝).
- **감독이 낸 개체의 체력**: `Mobs.spawn` 뒤(종의 `spawned()` 다음, 첫 `tick()` 전) 감독이 `maxHp`, `hp` 에 `hpMul(sp)` 를 곱한다. 종이 만든 `child` 에는 곱하지 않는다.
- **죽음 결과 종(G38, G52, G50)**: `noReward` 를 켜지 않는다(켜면 그 죽음을 사람이 잡은 것이 아니라 웨이브 끝 정리로 본다). 다른 개체로 바뀌면 `game.players.transferTrapped(from, to)`.

## 텍스처 이름 주의(2026-11-11 실서버에서 겪음)

- 텍스처 이름이 `_n`, `_s`, `_e` 로 끝나면 안 된다. Iris, OptiFine 같은 셰이더 모드가 PBR 노멀, 스페큘러, 발광 맵으로 보고 아틀라스에서 빼서, 그 텍스처를 쓰는 면이 보라 검정으로 나온다(바닐라 클라에서는 멀쩡해서 시험에서 안 잡힌다). 실서버 첫 판에서 가까운 얼굴 90장이 이렇게 깨졌다.
- 키트의 `_put` 이 끝 글자를 저절로 바꾼다(`_n` → `_nr`, `_s` → `_sp`, `_e` → `_em`). 종 스크립트는 `k.texture()` 가 돌려준 id 를 그대로 쓰면 되고, id 를 글자로 직접 이어 붙여 쓰지 않는다.

## 사람 찾는 반경 주의(2026-11-11 실서버에서 겪음)

- 게이브는 사람에게서 24~132블록 떨어진 곳(반경 72~84 고리, 하늘)에서 나오고, 사람은 멀리 있는 게이브도 쏜다. 그래서 어떤 상태든 "가까운 사람이 반경 r 안에 없으면 멈춤" 꼴이면 그 개체가 외곽에 남아 웨이브 끝을 막는다. 실서버 첫 판에서 막대기 하나가 끊긴 가오리(G01 SPIN, `nearest(48)`)가 외곽에서 제자리만 돌았다.
- 규칙: 다가오는 길에 있는 상태는 `nearest(400)` 으로 찾거나, 못 찾았을 때 `follow(speed())`(흐름장)로 온다. `hold()` 나 `return` 으로 끝내려면 그 상태에 틱 제한이 있어야 한다. 좁은 반경은 공격을 시작할 거리를 고를 때만 쓴다.
- 특히 위험한 곳: 맞아서 바뀌는 상태(부위 끊김, 분열, 기절), 죽은 자리에 생기는 개체(G26 같은 파생), 쫓던 사람이 쓰러지거나 나간 뒤, G55 가 가장자리로 끌어냈다 놓은 뒤.
- 시체나 다른 게이브를 따라가는 종은 그 대상이 사람에게서 먼 곳에 있을 때 같이 외곽에 묶이지 않게 한다(G11 은 서 있는 사람에게서 36블록 안의 시체만 먹는다).
- 확인 대본: `tools/scenarios/fix_approach.json`(RING, SKY 종을 80블록에 놓고 17초 뒤 거리), `fix_g01_spin.json`(멀리서 막대기가 끊긴 가오리), `fix2_far.json`(G26, G11, G50).
